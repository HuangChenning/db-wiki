# 达梦数据库 DM7 文档目录

路径都相对于本文件所在的 `html-to-md` 目录。检索时先选定一栏，再打开对应的 `contents.md`。

## 说明

- `welcome/contents.md`：DM7 欢迎使用DM帮助文档。说明帮助文档分成技术丛书和技术手册。
- `preface/contents.md`：DM7 前言。手册的读者对象、排版约定和相关文档。
- `support/contents.md`：DM7 技术支持。达梦技术支持的联系方式。

## SQL 与开发

- `sql-language/contents.md`：DM7 SQL语言使用手册。SQL 语句、函数和数据类型。
- `disql/contents.md`：DM7 DIsql使用手册。DIsql 命令行工具。
- `proc/contents.md`：DM7 PROC使用手册。嵌入式 SQL 预编译器 PROC。
- `dmpython/contents.md`：DM7 dmPython使用手册。用 dmPython 连接达梦并执行 SQL。
- `programmer/contents.md`：DM7程序员手册。DPI、ODBC、JDBC、.NET、PHP 和 DCI 编程接口。

## 管理

- `administrator/contents.md`：DM7系统管理员手册。实例结构、对象管理、调优、备份和升级。
- `security/contents.md`：DM7安全管理。用户、权限、审计、加密和资源限制。
- `backup-restore/contents.md`：DM7 新备份与还原。数据库备份与还原。
- `job-system/contents.md`：DM7 作业系统使用手册。作业的创建、调度和监控。

## 高可用与集群

- `data-watch/contents.md`：DM7数据守护概念与管理。数据守护的概念、搭建和日常管理。
- `data-watch-v2/contents.md`：DM7数据守护V2.0。数据守护 V2.0 的概念与管理。
- `read-write-split/contents.md`：DM7可靠的读写分离系统操作手册。读写分离集群的配置和切换。
- `cluster-agent/contents.md`：DM7 集群代理使用手册。集群代理的配置和使用。

## 工具

- `dminit/contents.md`：DM7 dminit使用手册。用 dminit 初始化数据库。
- `dmfldr/contents.md`：DM7 dmfldr使用手册。用 dmfldr 快速装载数据。
- `dmdbchk/contents.md`：DM7 dmdbchk使用手册。用 dmdbchk 检查数据文件、索引和对象。
- `dexp-dimp/contents.md`：DM7 dexp和dimp使用手册。用 dexp 逻辑导出，用 dimp 逻辑导入。
- `dmlcvt/contents.md`：DM7 dmlcvt使用手册。用 dmlcvt 解析联机日志和归档日志。
