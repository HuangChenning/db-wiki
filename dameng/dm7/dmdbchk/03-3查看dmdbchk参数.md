`dmdbchk`使用简单灵活。用户可使用`“dmdbchk HELP”`快速查看参数用法。

```
./dmdbchk HELP
格式: ./dmdbchk ini_file_path
例程: ./dmdbchk path=/opt/dmdbms/bin/dm.ini
关键字 说明（默认）
-----------------------------------------------------------------------------
PATH dm.ini绝对路径或者当前目录的dm.ini
HELP 打印帮助信息
```
