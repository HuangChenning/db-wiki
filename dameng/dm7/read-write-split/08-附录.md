## 附录1 系统视图

用于主备环境下的一些系统信息查询：

1. V$UTSK_SYS

查询守护进程向服务器发送请求的执行情况。

注意在RUNNING 字段值为TRUE 时，DSEQ、CODE 和SEND_LSN 的值才有意义，CAN_TAKEOVER 和 AUTO_SWITCH 字段只用于普通主备系统，读写分离主备和MPP 主备下这两个字段没有意义，都是FALSE。

序号列数据类型说明1 RUNNING VARCHAR(64) 当前系统是否正在处理守护进程请求，TRUE表示正在处理，FALSE 表示没有。

2 DSEQ INTEGER 发送报文序号3 CODE INTEGER DSEQ 对应的执行结果4 SEND_LSN BIGINT 主库发送给备库的最大归档LSN 5 CAN_TAKEOVER VARCHAR(64) 非自动切换模式下，能否takeover 主库，TRUE允许执行takeover，FALSE 不允许执行6 AUTO_SWITCH VARCHAR(64) Watch 的切换模式，TRUE 自动切换，FALSE非自动切换

2. V$RECOVER_STATUS

该视图需要在主库上查询，用于查询备库的恢复进度，如果已恢复完成，查询结果为空。

注意这里显示的是主库向备库发送日志的进度，由于备库重做日志也需要时间，在最后一批日志发送完成后，KBYTES_TO_RECOVER 为0，RECOVER_PERCENT 为100%，表示主库已经完成所有日志发送，需要等待备库将最后一批日志重做完成。

RECOVER_PERCENT = (KBYTES_TOTAL - KBYTES_TO_RECOVER)/KBYTES_TOTAL

序号列数据类型说明1 PRIMARY_NAME VARCHAR(256) 主库实例名2 STANDBY_NAME VARCHAR(256) 主库正在恢复的备库实例名3 PRIM_LSN BIGINT 主库当前的FLSN 4 SEND_LSN BIGINT 主库已发给备库的最大LSN 5 KBYTES_TOTAL BIGINT 主库本地的日志总量，单位为KB 6 KBYTES_TO_RECOVER BIGINT 主库需要发送给备库的日志量，单位为KB 7 FILES_TO_RECOVER INTEGER 主库需要发给备库重做的日志文件个数8 RECOVER_PERCENT VARCHAR(64) 主库向备库已发送日志的比例

3. V$RAPPLY_SYS

该视图需要在备库上查询，用于查询备库重做日志时的一些系统信息。

序号列数据类型说明1 APPLYING VARCHAR(64) 备库的重做线程是否正在处理任务，查询结果为TRUE 或FALSE 2 SEC_MAX_LSN BIGINT 备库收到的第二大LSN 值3 MAX_LSN BIGINT 备库收到的最大LSN 值4 TASK_NUM INTEGER 备库上的重做任务数5 PRIMARY_NAME VARCHAR(128) 主库实例名6 HAS_KEEP_BUF VARCHAR(64) 备库上是否有KEEP_BUF，查询结果为TRUE 或FALSE

4. V$RAPPLY_LOG_TASK

该视图需要在备库上查询，用于查询备库所有重做任务的日志信息。

序号列数据类型说明1 TYPE VARCHAR(64) 日志类型2 MIN_LSN BIGINT 日志的最小LSN 值3 MAX_LSN BIGINT 日志的最大LSN 值4 PTX_OFF SMALLINT 重做日志的PTX 偏移5 LOG_SIZE INTEGER 日志长度，单位为字节

5. V$ARCH_FILE

查询本地归档日志信息。

序号列数据类型说明1 DB_MAGIC INTEGER 数据库的MAGIC 值2 STATUS VARCHAR(64) 归档日志状态3 LEN BIGINT 日志长度，单位为字节4 FREE BIGINT 写日志偏移位置5 ARCH_LSN BIGINT 归档文件起始LSN，仅对归档文件有意义6 CLSN BIGINT 检查点的LSN 7 ARCH_SEQ INTEGER 归档文件起始SEQ，仅对归档文件有意义8 NEXT_SEQ INTEGER 下一个SEQ 值9 CREAT_TIME TIMESTAMP 归档文件创建时间10 CLOSE_TIME TIMESTAMP 归档文件关闭时间11 PATH VARCHAR(256) 归档文件所在路径，包括归档文件名

6. V$ARCH_STATUS

查询归档状态信息，包括本地归档和远程归档。

序号列数据类型说明1 ARCH_TYPE VARCHAR(256) 归档类型2 ARCH_DEST VARCHAR(256) 归档目标，本地归档为归档路径，其他类型为远程实例名。

3 ARCH_STATUS VARCHAR(256) 归档状态，VALID 为有效状态，INVALID为无效状态

7. V$MAL_LINK_STATUS

查询本地实例到远程的MAL 连接状态。

序号列数据类型说明1 SRC_SITE VARCHAR(256) 源站点实例名2 DEST_SITE VARCHAR(256) 目的站点实例名。

3 CTL_LINK_STATUS VARCHAR(256) 控制链路连接状态，CONNECTED 表示连接已建立，DISCONNECT 表示连接断开。

4 DATA_LINK_STATUS VARCHAR(256) 数据链路连接状态，CONNECTED 表示连接已建立，DISCONNECT 表示连接断开。

## 附录2 监视器接口

监视器提供动态链接库dmrwm_dll.dll/libdmrwm.so，供用户编程使用。

在调用接口时需要注意，由于监视器是根据守护进程发送过来的UDP或TCP消息来判断是否符合执行条件，如果监视器尚未收到消息，或者收到的UDP消息不可靠，很有可能会导致接口执行失败，可能需要尝试多次调用。

### 1.1 返回值说明

监视器接口总体的返回值策略为：小于0 表示执行失败，其他值表示执行成功。对于启动/关闭守护进程监控和实例的相关接口，返回值为100 表示执行前状态已经和预期结果一致，接口实际并未执行。相关的错误码说明请参考1.8 小节。

### 1.2 C 接口说明

由于监视器可以检测守护进程或实例的状态变化，同时也允许执行命令来管理守护系统，为了能够在接口调用时获取到系统的状态变化信息，或者执行命令时产生的步骤信息，监视器提供有等待和获取信息相关接口，具体用法见以下说明。

#### 1. 分配操作句柄

函数原型：

DMRWM_RETURN dmrwm_alloc_handle(mhandle* mhdl);

功能说明：

分配监视器操作句柄，监视器的接口都通过此句柄调用执行。

参数说明：

mhdl: 输出参数，分配到的句柄返回值：

0：分配成功<0：分配失败

#### 2. 初始化监视器环境

函数原型：

DMRWM_RETURN dmrwm_init(mhandle mhdl,mchar* ini_path,mchar* log_path);

功能说明：

初始化监视器的环境参数说明：

mhdl: 输入参数，监视器操作句柄ini_path: 输入参数，指定dmrwm.ini 的绝对路径log_path: 输入参数，指定日志文件的存放路径，如果为NULL 或空串，则不生成日志文件返回值：

0：执行成功<0：执行失败

#### 3. 等待消息事件

函数原型：

void dmrwm_msg_event_wait(mhandle mhdl);

功能说明：

监视器检测到守护进程或实例状态发生变化，或者接口命令执行过程中，产生中间输出消息时会将消息写入到缓存并通知消息事件，调用者只需要调用此接口等待即可，等待事件发生后，可通过接口dmrwm_get_exec_msg 去读取中间结果。

这种方式需要单独起一个线程来处理消息，以免消息被阻塞。

参数说明：

mhdl: 输入参数，监视器操作句柄返回值：

无

#### 4. 获取输出信息

函数原型：

DMRWM_RETURN dmrwm_get_exec_msg(mhandle mhdl,mchar* buf_msg,muint4 buf_len,muint4* msg_len_out,muint4* get_flag);

功能说明：

获取输出信息，和dmrwm_msg_event_wait 配合使用。

参数说明：

mhdl:输入参数，监视器操作句柄buf_msg：

输出参数，保存获取到的输出消息，注意buf_msg 缓存长度需要大于2048，以免长度不够导致消息被截断。

buf_len:输入参数，指定buf_msg 可写入的最大长度，建议buf_msg 缓存长度及buf_len 输入值大于2048，避免消息被截断。

msg_len_out:输出参数，写消息成功后，实际写入的消息长度保存到msg_len_out 中。

get_flag:输出参数，是否继续读取消息，TRUE 表示还有消息可读，FALSE 表示已全部读完。

返回值：

0：执行成功<0：执行失败

#### 5. 设置自动显示间隔

函数原型：

DMRWM_RETURN dmrwm_set_show_interval(mhandle mhdle,mint4 show_interval);

功能说明：

监视器根据指定的show_interval 值，每隔show_interval 个时间间隔，自动输出各实例的状态信息给用户，需要使用dmrwm_get_exec_msg 接口获取到输出消息，show_interval 单位为秒，默认值为0。

参数说明：

mhdle: 输入参数，监视器操作句柄show_interval: 输入参数，设置定时输出状态信息的时间间隔，单位为秒，取值为0，或5~3600，取值为0 表示取消自动输出，默认值为0。

返回值：

<0：执行失败其他值：执行成功

#### 6. 获取自动显示间隔

函数原型：

DMRWM_RETURN dmrwm_get_show_interval(mhandle mhdle);

功能说明：

获取当前设置的显示时间间隔，单位为秒。

参数说明：

mhdle: 输入参数，监视器操作句柄返回值：

<0：获取失败其他值：当前设置的自动显示时间间隔

#### 7. 设置自动写入日志文件间隔

函数原型：

DMRWM_RETURN dmrwm_set_log_interval(mhandle mhdle,mint4 log_interval);

功能说明：

监视器按照设置的log_interval 值，每隔log_interval 个时间间隔，自动将各实例的状态信息写入到日志文件，log_interval 单位为秒，默认值为1。

参数说明：

mhdle: 输入参数，监视器操作句柄log_interval: 输入参数，设置定时写入状态信息到日志文件的时间间隔，单位为秒，取值为0，1 或5~3600。

取值为0 表示不写入任何信息到日志文件。

取值为1 表示只写入普通的状态变化日志，例如收到新的信息或者检测到状态变化等。

取值为5~3600 范围内的数值时，除了生成普通日志信息外，会按照设置的间隔定期写入站点状态信息到日志文件中。

返回值：

<0：执行失败其他值：执行成功
