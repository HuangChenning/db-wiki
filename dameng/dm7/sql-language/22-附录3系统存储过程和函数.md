以下为达梦数据库所用到的系统存储过程和函数。

注：函数名右上角有`“*”`标记的，表示此过程/函数的使用有下面两点限制：

1. 此过程/函数不能在`MPP` 全局模式下的存储过程中直接调用，在`MPP LOCAL` 模式

下可在存储过程中直接调用；

2. 此过程/函数不能在存储过程中带参数进行动态调用。

## 1) 系统信息管理

```
1) SF_GET_PARA_VALUE
```

定义：

```
int
SF_GET_PARA_VALUE (
scope           int,
ini_param_name  varchar(256)
)
```

功能说明：

返回`dm.ini`文件中非浮点和字符串类型的参数值参数说明：

`scope`： 取值为1、2。 1 表示从`dm.ini`文件中读取；2 表示从内存中读取；`ini_param_name`：`dm.ini`文件中的参数名返回值：

当前`INI`文件中对应的参数值，如果参数不在`dm.ini`中则读取失败举例说明：

获得`dm.ini`文件中`BUFFER`参数值

```
SELECT SF_GET_PARA_VALUE (1, 'BUFFER');
2) SP_SET_PARA_VALUE*
```

定义：

```
void
SP_SET_PARA_VALUE (
scope           int,
ini_param_name  varchar(256)
value           bigint
)
```

功能说明：

设置`dm.ini`文件中非浮点和字符串类型的参数值参数说明：

`scope`：取值为1，2。1 表示`dm.ini`文件和内存参数都已修改，不需要重启服务器，不在`ini`文件中的参数则只修改内存值；2 表示只修改`dm.ini`文件，服务器重启后生效，如果不在`ini`文件中的参数则修改`dm.ini`文件报错。

`ini_param_name`：`dm.ini`文件中的参数名。

`value`：设置的值。

返回值：

无举例说明：

将`dm.ini`文件中`HFS_CACHE_SIZE`参数值设置为320

```
SP_SET_PARA_VALUE (1,'HFS_CACHE_SIZE',320);
```

```
10) SF_SET_SYSTEM_PARA_VALUE*
```

定义：

```
INT
SF_SET_SYSTEM_PARA_VALUE (
paraname varchar(256),
value bigint\double\varchar(256),
deferred int,
scope int)
```

功能说明：

修改系统整型、`double`、`varchar`的静态配置参数或动态配置参数。

参数说明：

`paraname`：`ini`参数的参数名`value`：要设置的新值`deferred`：是否立即生效。为0 表示当前`session`修改的参数立即生效，为1 表示当前`session`不生效，后续再生效，默认为0。

`scope`：取值为0、1、2。0 表示修改内存中的参数值，1 表示修改内存和`INI`文件中参数值，0 和1 都只能修改动态的配置参数。2 表示修改`INI`文件中参数，此时可用来修改静态配置参数和动态配置参数。

返回值：

执行成功返回`null`，执行错误返回错误码举例说明：

修改`INI`参数`JOIN_HASH_SIZE`的值：

```
SELECT SF_SET_SYSTEM_PARA_VALUE ('JOIN_HASH_SIZE',50,1,1);
```

## 16) HUGE 表备份还原

目前暂时只提供单独的`huge`表备份还原系统函数，每次备份都是完全备份，不支持增量备份。 `HUGE`表备份还原为联机执行。不需要配置归档。

函数需要使用`utl_file`包，所以需要先建系统包。

```
SP_CREATE_SYSTEM_PACKAGES(1);
1. SP_BACKUP_HUGE_TABLE
```

定义：

```
SP_BACKUP_HUGE_TABLE(
SCHNAME  VARCHAR2(128),
TNAME  VARCHAR2(128),
BAK_PATH  VARCHAR2(256),
DEL_FLAG  BOOLEAN
);
```

参数说明：

`SCHNAME`：模式名`TNAME`：表名`BAK_PATH`：备份路径。也可以指定为`NULL`或者`''`，这种情况下，数据会备份到默认备份路径（在`dm.ini`里面由`BAK_PATH`指定）。`MPP`环境下，如果站点都在同一台机器上，`BAK_PATH`只能指定`NULL`或者`''``DEL_FLAG`：备份目录存在情况下，是否删除功能说明：

单表备份语句。

举例说明：

```
SP_BACKUP_HUGE_TABLE('SYSDBA', 'HTEST', 'D:\DATA\HUGE_BAK', TRUE);
2. SP_RESTORE_HUGE_TABLE
SP_RESTORE_HUGE_TABLE(
SCHNAME  VARCHAR2(128),
TNAME  VARCHAR2(128),
BAK_PATH  VARCHAR2(256),
DEL_FLAG  BOOLEAN
);
```

参数说明：

`SCHNAME`：模式名`TNAME`：表名`BAK_PATH`：备份路径。也可以指定为`NULL`或者`''`，这种情况下，会到默认备份路径（在`dm.ini`里面由`BAK_PATH`指定）寻找备份文件。`MPP`环境下，如果站点都在同一台机器上，`BAK_PATH`只能指定`NULL`或者`''``DEL_FLAG`：表已存在的情况下，是否删除功能说明：

单表还原语句。

举例说明：

```
SP_RESTORE_HUGE_TABLE('SYSDBA', 'HTEST', 'D:\DATA\HUGE_BAK', TRUE);
3. SP_BACKUP_ALL_HUGE_TABLE
SP_BACKUP_ALL_HUGE_TABLE(
BAK_PATH  VARCHAR2(256),

DEL_FLAG  BOOLEAN
);
```

参数说明：

`BAK_PATH`：备份路径，指定的路径必须已经存在。也可以指定为`NULL`或者`''`，这种情况下，数据会备份到默认备份路径（在`dm.ini`里面由`BAK_PATH`指定）。`MPP`环境下，如果站点都在同一台机器上，`BAK_PATH`只能指定`NULL`或者`''``LOG_NAME`：日志名称。日志中记录所备份的表名，格式为：`SCHNAME,TNAME`。
