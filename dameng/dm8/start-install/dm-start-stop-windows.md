## 一、启动达梦服务查看器

在计算机【开始】栏找到【DM 服务查看器】快捷方式并打开。

或者在数据库安装目录下 tool 目录例如 D:\\dmdba\\dmdbms\\tool 中找到 dmservice 应用程序并双击启动。

![image.png](img/202401231501289RYMLNNTQWUDGPGGBO.png)

## 二、启、停数据库服务

可以通过【DM 服务查看器】查看到对应的 DM 服务，可选择【启动】或【停止】对应的服务，如下图所示：
