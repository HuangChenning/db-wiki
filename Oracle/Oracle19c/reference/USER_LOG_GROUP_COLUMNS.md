## 6.540 USER\_LOG\_GROUP\_COLUMNS

`USER_LOG_GROUP_COLUMNS` describes columns that are owned by the current user and that are specified in log groups. Its columns are the same as those in `ALL_LOG_GROUP_COLUMNS`.
