## 6.459 USER\_FILE\_GROUP\_FILES

`USER_FILE_GROUP_FILES` shows the file set for each versioned group owned by the current user. Its columns (except for `FILE_GROUP_OWNER`) are the same as those in `ALL_FILE_GROUP_FILES`.
