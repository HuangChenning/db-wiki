## 6.706 USER\_TAB\_PRIVS\_MADE

`USER_TAB_PRIVS_MADE` describes the object grants for which the current user is the object owner. Its columns (except for `OWNER`) are the same as those in `ALL_TAB_PRIVS_MADE`.
