## 6.57 DBA\_TRIGGERS\_AE

`DBA_TRIGGERS_AE` describes all triggers (across all editions) in the database. Its columns are the same as those in `ALL_TRIGGERS_AE`.

Note:

This view is available starting with Oracle Database 19c.
