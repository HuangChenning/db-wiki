## 6.695 USER\_TAB\_COL\_STATISTICS

`USER_TAB_COL_STATISTICS` contains column statistics and histogram information extracted from `USER_TAB_COLUMNS`.

Its columns (except for `OWNER`) are the same as those in `ALL_TAB_COL_STATISTICS`.
