## 4.109 DBA\_APPLY\_HANDLE\_COLLISIONS

`DBA_APPLY_HANDLE_COLLISIONS` provides details about apply handlers for collisions at the table level. Its columns are the same as those in `ALL_APPLY_HANDLE_COLLISIONS`.
