## 6.397 USER\_COMPARISON\_COLUMNS

`USER_COMPARISON_COLUMNS` displays information about the columns for the comparison objects owned by the current user. Its columns (except for `OWNER`) are the same as those in `DBA_COMPARISON_COLUMNS`.
