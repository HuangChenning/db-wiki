## 5.180 DBA\_MINING\_MODEL\_PARTITIONS

`DBA_MINING_MODEL_PARTITIONS` describes all the model partitions accessible to the system. Its columns are the same as those in `ALL_MINING_MODEL_PARTITIONS`.
