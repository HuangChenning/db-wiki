## 6.327 USER\_ANALYTIC\_VIEW\_LVLGRPS\_AE

`USER_ANALYTIC_VIEW_LVLGRPS_AE` describes the analytic view measure and level groups of the analytic views (across all editions) owned by the current user. Its columns (except for `OWNER`) are the same as those in `ALL_ANALYTIC_VIEW_LVLGRPS_AE`.

Note:

This view is available starting with Oracle Database 19c, Release Update 19.13.
