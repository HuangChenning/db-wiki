## 6.537 USER\_LOB\_SUBPARTITIONS

`USER_LOB_SUBPARTITIONS` displays partition-level attributes of the LOB data subpartitions owned by the current user. Its columns are the same as those in `ALL_LOB_SUBPARTITIONS`.

`DBA_LOB_TEMPLATES` describes all LOB subpartition templates in the database.
