## 5.106 DBA\_IMMUTABLE\_TABLES

`DBA_IMMUTABLE_TABLES` describes all immutable tables in the database. Its columns are the same as those in `ALL_IMMUTABLE_TABLES`.

Note:

This view is available starting with Oracle Database 19c, Release Update 19.11.
