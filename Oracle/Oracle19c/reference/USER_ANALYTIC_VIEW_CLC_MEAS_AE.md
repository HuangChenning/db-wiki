## 6.305 USER\_ANALYTIC\_VIEW\_CLC\_MEAS\_AE

`USER_ANALYTIC_VIEW_CLC_MEAS_AE` describes the calculated measures in the analytic views (across all editions) owned by the current user. Its columns (except for `OWNER`) are the same as those in `ALL_ANALYTIC_VIEW_CLC_MEAS_AE`.

Note:

This view is available starting with Oracle Database 19c, Release Update 19.13.
