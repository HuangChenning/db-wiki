## 6.413 USER\_CUBE\_DIM\_VIEWS

`USER_CUBE_DIM_VIEWS` describes the relational views of the OLAP dimensions owned by the current user. Its columns (except for `OWNER`) are the same as those in `ALL_CUBE_DIM_VIEWS`.
