## 6.525 USER\_JAVA\_NCOMPS

`USER_JAVA_NCOMPS` displays `ncomp` -related information about the Java classes owned by the current user. Its columns (except for `OWNER`) are the same as those in `ALL_JAVA_NCOMPS`.
