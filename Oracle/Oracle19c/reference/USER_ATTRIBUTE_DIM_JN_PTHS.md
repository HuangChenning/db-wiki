## 6.348 USER\_ATTRIBUTE\_DIM\_JN\_PTHS

`USER_ATTRIBUTE_DIM_JN_PTHS` is identical to `USER_ATTRIBUTE_DIM_JOIN_PATHS`.

Note:

This view is available starting with Oracle Database 19c, Release Update 19.13.
