## 4.113 DBA\_APPLY\_KEY\_COLUMNS

`DBA_APPLY_KEY_COLUMNS` displays information about the substitute key columns for all tables in the database. Its columns are the same as those in `ALL_APPLY_KEY_COLUMNS`.
