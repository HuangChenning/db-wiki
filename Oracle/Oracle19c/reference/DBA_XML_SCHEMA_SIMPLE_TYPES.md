## 6.139 DBA\_XML\_SCHEMA\_SIMPLE\_TYPES

`DBA_XML_SCHEMA_SIMPLE_TYPES` describes all simple types. Its columns are the same as those in `ALL_XML_SCHEMA_SIMPLE_TYPES`.
