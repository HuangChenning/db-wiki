## 6.598 USER\_PENDING\_CONV\_TABLES

`USER_PENDING_CONV_TABLES` describes the pending conversion tables owned by the current user. Its columns (except for `OWNER`) are the same as those in `ALL_PENDING_CONV_TABLES`.
