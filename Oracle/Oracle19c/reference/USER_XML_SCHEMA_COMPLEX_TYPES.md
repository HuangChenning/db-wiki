## 6.740 USER\_XML\_SCHEMA\_COMPLEX\_TYPES

`USER_XML_SCHEMA_COMPLEX_TYPES` describes all complex types owned by the current user. Its columns (except for `OWNER`) are the same as those in `ALL_XML_SCHEMA_COMPLEX_TYPES`.
