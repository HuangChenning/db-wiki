## 2.76 ALL\_ATTRIBUTE\_DIM\_ATTR\_CLS

`ALL_ATTRIBUTE_DIM_ATTR_CLS` is identical to `ALL_ATTRIBUTE_DIM_ATTR_CLASS`.

Note:

This view is available starting with Oracle Database 19c, Release Update 19.13.
