## 6.411 USER\_CUBE\_DIM\_MODELS

`USER_CUBE_DIM_MODELS` describes the models for the OLAP dimensions owned by the current user. Its columns (except for `OWNER`) are the same as those in `ALL_CUBE_DIM_MODELS`.
