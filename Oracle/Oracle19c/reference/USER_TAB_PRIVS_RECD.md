## 6.707 USER\_TAB\_PRIVS\_RECD

`USER_TAB_PRIVS_RECD` describes the object grants for which the current user is the grantee. Its columns (except for `GRANTEE`) are the same as those in `ALL_TAB_PRIVS_RECD`.
