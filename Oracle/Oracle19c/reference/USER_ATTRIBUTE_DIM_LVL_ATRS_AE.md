## 6.357 USER\_ATTRIBUTE\_DIM\_LVL\_ATRS\_AE

`USER_ATTRIBUTE_DIM_LVL_ATRS_AE` describes the attributes of the levels of the attribute dimensions (across all editions) owned by the current user. Its columns (except for `OWNER`) are the same as those in `ALL_ATTRIBUTE_DIM_LVL_ATRS_AE`.

Note:

This view is available starting with Oracle Database 19c, Release Update 19.13.
