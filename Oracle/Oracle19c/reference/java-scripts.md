## B.5 Java Scripts

The Java scripts are useful only if the JServer option is installed.

Table B-4 Java Scripts

| Script Name | Description |
| --- | --- |
| `initjvm.sql` | Initializes JServer by installing core Java class libraries and Oracle-specific Java classes |
| `rmjvm.sql` | Removes all elements of the JServer  See Also: [Oracle Database Java Developer’s Guide](https://docs.oracle.com/pls/topic/lookup?ctx=en/database/oracle/oracle-database/19/refrn&id=JJDEV13550) |
| `catjava.sql` | Installs Java-related packages and classes |
