## 4.132 DBA\_ATTRIBUTE\_DIM\_CLASS\_AE

`DBA_ATTRIBUTE_DIM_CLASS_AE` describes the classifications of all attribute dimensions (across all editions) in the database. Its columns are the same as those in `ALL_ATTRIBUTE_DIM_CLASS_AE`.

Note:

This view is available starting with Oracle Database 19c, Release Update 19.13.
