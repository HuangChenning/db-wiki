## 6.335 USER\_ANNOTATIONS\_USAGE

`USER_ANNOTATIONS_USAGE` provides usage information about schema annotations owned by the current user. Its columns (except for `ANNOTATION_OWNER`) are the same as those in `ALL_ANNOTATIONS_USAGE`.

The annotation owner is the same as the owner of the annotated object.

Note:

This view is available starting with Oracle Database 19c, Release Update 19.28.
