## 5.179 DBA\_MINING\_MODEL\_ATTRIBUTES

`DBA_MINING_MODEL_ATTRIBUTES` describes all mining model attributes in the database. Its columns are the same as those in `ALL_MINING_MODEL_ATTRIBUTES`.
