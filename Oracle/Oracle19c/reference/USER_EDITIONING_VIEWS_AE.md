## 6.445 USER\_EDITIONING\_VIEWS\_AE

`USER_EDITIONING_VIEWS_AE` describes the editioning views (across all editions) owned by the current user. Its columns (except for `OWNER`) are the same as those in `ALL_EDITIONING_VIEWS_AE`.
