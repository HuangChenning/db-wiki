## 4.182 DBA\_BLOCKCHAIN\_TABLES

`DBA_BLOCKCHAIN_TABLES` describes all blockchain tables in the database. Its columns are the same as those in `ALL_BLOCKCHAIN_TABLES`.

Note:

This view is available starting with Oracle Database 19c, Release Update 19.10.
