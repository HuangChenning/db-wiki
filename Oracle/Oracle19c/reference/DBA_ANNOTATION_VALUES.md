## 4.90 DBA\_ANNOTATION\_VALUES

`DBA_ANNOTATION_VALUES` displays the values for all schema annotations in the database. Its columns are the same as those in `ALL_ANNOTATION_VALUES`.

Note:

This view is available starting with Oracle Database 19c, Release Update 19.28.
