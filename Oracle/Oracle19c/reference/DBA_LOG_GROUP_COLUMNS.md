## 5.155 DBA\_LOG\_GROUP\_COLUMNS

`DBA_LOG_GROUP_COLUMNS` describes all columns in the database that are specified in log groups. Its columns are the same as those in `ALL_LOG_GROUP_COLUMNS`.
