## 6.137 DBA\_XML\_SCHEMA\_ELEMENTS

`DBA_XML_SCHEMA_ELEMENTS` describes all the elements and their properties. Its columns are the same as those in `ALL_XML_SCHEMA_ELEMENTS`.
