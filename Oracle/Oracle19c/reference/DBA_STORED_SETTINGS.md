## 5.395 DBA\_STORED\_SETTINGS

`DBA_STORED_SETTINGS` lists information about the persistent parameter settings for stored PL/SQL units for which the current user has execute privileges.

It also returns parameter information for all objects in the database and is accessible only to users with the `SELECT_CATALOG_ROLE` privilege. Its columns are the same as those in `ALL_STORED_SETTINGS`.
