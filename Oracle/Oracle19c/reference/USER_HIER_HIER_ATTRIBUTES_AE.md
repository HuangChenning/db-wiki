## 6.479 USER\_HIER\_HIER\_ATTRIBUTES\_AE

`USER_HIER_HIER_ATTRIBUTES_AE` describes the hierarchical attributes of the hierarchies (across all editions) owned by the current user. Its columns (except for `OWNER`) are the same as those in `ALL_HIER_HIER_ATTRIBUTES_AE`.

Note:

This view is available starting with Oracle Database 19c, Release Update 19.13.
