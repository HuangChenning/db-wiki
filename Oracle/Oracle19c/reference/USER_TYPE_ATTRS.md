## 6.723 USER\_TYPE\_ATTRS

`USER_TYPE_ATTRS` describes the attributes of the object types owned by the current user. Its columns (except for `OWNER` and `CHAR_USED`) are the same as those in `ALL_TYPE_ATTRS`.
