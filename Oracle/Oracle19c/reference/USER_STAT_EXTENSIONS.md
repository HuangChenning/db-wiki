## 6.685 USER\_STAT\_EXTENSIONS

`USER_STAT_EXTENSIONS` displays information about the optimizer statistics extensions owned by the current user. Its columns (except for `OWNER`) are the same as those in `ALL_STAT_EXTENSIONS`.
