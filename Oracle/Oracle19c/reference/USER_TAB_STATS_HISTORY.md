## 6.710 USER\_TAB\_STATS\_HISTORY

`USER_TAB_STATS_HISTORY` provides a history of table statistics modifications for all tables owned by the current user. Its columns (except for `OWNER`) are the same as those in `ALL_TAB_STATS_HISTORY`.
