## 6.11 DBA\_STREAMS\_TABLE\_RULES

`DBA_STREAMS_TABLE_RULES` displays information about the table rules created for all capture processes, propagations, and apply processes in the database. Its columns are the same as those in `ALL_STREAMS_TABLE_RULES`.
