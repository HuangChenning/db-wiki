## 4.147 DBA\_ATTRIBUTE\_DIM\_ORD\_ATRS\_AE

`DBA_ATTRIBUTE_DIM_ORD_ATRS_AE` describes the order attributes of all attribute dimensions (across all editions) in the database. Its columns are the same as those in `ALL_ATTRIBUTE_DIM_ORD_ATRS_AE`.

Note:

This view is available starting with Oracle Database 19c, Release Update 19.13.
