## 6.419 USER\_CUBE\_HIERARCHIES

`USER_CUBE_HIERARCHIES` describes the OLAP dimension hierarchies owned by the current user. Its columns (except for `OWNER`) are the same as those in `ALL_CUBE_HIERARCHIES`.
