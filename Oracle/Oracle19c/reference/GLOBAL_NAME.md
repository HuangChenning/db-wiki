## 6.188 GLOBAL\_NAME

`GLOBAL_NAME` contains one row that displays the global name of the current database.

| Column | Datatype | NULL | Description |
| --- | --- | --- | --- |
| `GLOBAL_NAME` | `VARCHAR2(4000)` |  | Global name of the database |
