## 4.91 DBA\_ANNOTATIONS

`DBA_ANNOTATIONS` displays all schema annotations in the database. Its columns are the same as those in `ALL_ANNOTATIONS`.

Note:

This view is available starting with Oracle Database 19c, Release Update 19.28.
