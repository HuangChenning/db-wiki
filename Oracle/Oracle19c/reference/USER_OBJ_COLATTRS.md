## 6.575 USER\_OBJ\_COLATTRS

`USER_OBJ_COLATTRS` describes object columns and attributes contained in the tables owned by the current user. Its columns (except for `OWNER`) are the same as those in `ALL_OBJ_COLATTRS`.
