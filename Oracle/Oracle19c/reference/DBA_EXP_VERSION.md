## 4.289 DBA\_EXP\_VERSION

`DBA_EXP_VERSION` displays the version number of the last export session.

| Column | Datatype | NULL | Description |
| --- | --- | --- | --- |
| `EXP_VERSION` | `NUMBER(3)` | `NOT NULL` | Version number of the last export session |
