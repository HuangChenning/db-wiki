## 6.338 USER\_ARGUMENTS

`USER_ARGUMENTS` lists the arguments of the functions and procedures that are owned by the current user. Its columns (except for `OWNER`) are the same as those in `ALL_ARGUMENTS`.

See Also:

- " [ALL\_ARGUMENTS](ALL_ARGUMENTS.md) "
- " [USER\_PROCEDURES](USER_PROCEDURES.md) " for information about the functions and procedures that are owned by the current user
