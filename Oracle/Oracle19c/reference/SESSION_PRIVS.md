## 6.241 SESSION\_PRIVS

`SESSION_PRIVS` describes the system privileges that are currently available to the user.

| Column | Datatype | NULL | Description |
| --- | --- | --- | --- |
| `PRIVILEGE` | `VARCHAR2(40)` | `NOT NULL` | Name of the privilege |
