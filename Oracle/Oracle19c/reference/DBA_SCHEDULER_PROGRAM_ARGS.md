## 5.334 DBA\_SCHEDULER\_PROGRAM\_ARGS

`DBA_SCHEDULER_PROGRAM_ARGS` displays information about the arguments of all Scheduler programs in the database. Its columns are the same as those in `ALL_SCHEDULER_PROGRAM_ARGS`.
