## 5.345 DBA\_SCHEDULER\_WINDOW\_LOG

`DBA_SCHEDULER_WINDOW_LOG` displays log information for all Scheduler windows in the database. Its columns are the same as those in `ALL_SCHEDULER_WINDOW_LOG`.
