## 4.285 DBA\_EVALUATION\_CONTEXT\_VARS

`DBA_EVALUATION_CONTEXT_VARS` describes the variables in all rule evaluation contexts in the database. Its columns are the same as those in `ALL_EVALUATION_CONTEXT_VARS`.
