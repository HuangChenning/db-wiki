## 6.415 USER\_CUBE\_DIMENSIONS

`USER_CUBE_DIMENSIONS` describes the OLAP cube dimensions owned by the current user. Its columns (except for `OWNER`) are the same as those in `ALL_CUBE_DIMENSIONS`.
