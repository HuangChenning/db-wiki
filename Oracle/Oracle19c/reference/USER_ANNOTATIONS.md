## 6.334 USER\_ANNOTATIONS

`USER_ANNOTATIONS` displays schema annotations owned by the current user. Its columns (except for `ANNOTATION_OWNER`) are the same as those in `ALL_ANNOTATIONS`.

The annotation owner is the same as the owner of the annotated object.

Note:

This view is available starting with Oracle Database 19c, Release Update 19.28.
