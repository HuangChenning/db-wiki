## 6.480 USER\_HIER\_JOIN\_PATHS

`USER_HIER_JOIN_PATHS` describes the join paths for the hierarchies owned by the current user. Its columns (except for `OWNER`) are the same as those in `ALL_HIER_JOIN_PATHS`.
