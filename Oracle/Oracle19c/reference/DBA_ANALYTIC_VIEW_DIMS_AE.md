## 4.70 DBA\_ANALYTIC\_VIEW\_DIMS\_AE

`DBA_ANALYTIC_VIEW_DIMS_AE` describes the attribute dimensions in all analytic views (across all editions) in the database. Its columns are the same as those in `ALL_ANALYTIC_VIEW_DIMS_AE`.

Note:

This view is available starting with Oracle Database 19c, Release Update 19.13.
