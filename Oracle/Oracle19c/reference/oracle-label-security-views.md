## 2.8 Oracle Label Security Views

Descriptions of Oracle Label Security views are not provided in this manual.

See [Oracle Label Security Administrator’s Guide](https://docs.oracle.com/pls/topic/lookup?ctx=en/database/oracle/oracle-database/19/refrn&id=OLSAG3626) for descriptions of Oracle Label Security views.

Note:

Oracle Label Security views include `_SA_` in the view name.
