## 4.150 DBA\_ATTRIBUTE\_DIM\_TABLES\_AE

`DBA_ATTRIBUTE_DIM_TABLES_AE` describes the tables used by all attribute dimensions (across all editions) in the database. Its columns are the same as those in `ALL_ATTRIBUTE_DIM_TABLES_AE`.

Note:

This view is available starting with Oracle Database 19c, Release Update 19.13.
