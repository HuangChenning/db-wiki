## 4.149 DBA\_ATTRIBUTE\_DIM\_TABLES

`DBA_ATTRIBUTE_DIM_TABLES` describes the tables used by all attribute dimensions in the database. Its columns are the same as those in `ALL_ATTRIBUTE_DIM_TABLES`.
