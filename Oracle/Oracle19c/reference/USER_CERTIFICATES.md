## 6.380 USER\_CERTIFICATES

`USER_CERTIFICATES` displays the certificates added by the current user which are used for signature verification for blockchain tables. Its columns (except `USER_NAME`) are the same as those in `ALL_CERTIFICATES`.

Note:

This view is available starting with Oracle Database 19c, Release Update 19.10.
