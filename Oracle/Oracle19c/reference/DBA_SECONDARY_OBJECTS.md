## 5.349 DBA\_SECONDARY\_OBJECTS

`DBA_SECONDARY_OBJECTS` provides information about all secondary objects that are associated with domain indexes in the database.

This view is only relevant in the context of domain indexes. Its columns are the same as those in " [ALL\_SECONDARY\_OBJECTS](ALL_SECONDARY_OBJECTS.md) ".
