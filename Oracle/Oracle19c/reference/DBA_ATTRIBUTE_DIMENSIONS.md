## 4.151 DBA\_ATTRIBUTE\_DIMENSIONS

`DBA_ATTRIBUTE_DIMENSIONS` describes all attribute dimensions in the database. Its columns are the same as those in `ALL_ATTRIBUTE_DIMENSIONS`.
