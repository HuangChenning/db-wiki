## 6.487 USER\_HIERARCHIES\_AE

`USER_HIERARCHIES_AE` describes the hierarchies (across all editions) owned by the current user. Its columns (except for `OWNER`) are the same as those in `ALL_HIERARCHIES_AE`.

Note:

This view is available starting with Oracle Database 19c, Release Update 19.13.
