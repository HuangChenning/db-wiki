## 5.174 DBA\_MEASURE\_FOLDER\_SUBFOLDERS

`DBA_MEASURE_FOLDER_SUBFOLDERS` describes the OLAP measure folders contained within the database OLAP measure folders. Its columns are the same as those in `ALL_MEASURE_FOLDER_SUBFOLDERS`.
