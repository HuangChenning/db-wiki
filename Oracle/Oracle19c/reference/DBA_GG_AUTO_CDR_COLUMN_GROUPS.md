## 4.310 DBA\_GG\_AUTO\_CDR\_COLUMN\_GROUPS

`DBA_GG_AUTO_CDR_COLUMN_GROUPS` provides details about all of the Oracle GoldenGate automatic conflict detection and resolution (CDR) column groups in the database.

Its columns are the same as those in `ALL_GG_AUTO_CDR_COLUMN_GROUPS`.
