## 6.722 USER\_TUNE\_MVIEW

`USER_TUNE_MVIEW` displays the result of executing the `DBMS_ADVISOR.TUNE_MVIEW` procedure. Its columns (except for `OWNER`) are the same as those in `DBA_TUNE_MVIEW`.
