## 4.330 DBA\_HIER\_CLASS\_AE

`DBA_HIER_CLASS_AE` describes the classifications of all hierarchies (across all editions) in the database. Its columns are the same as those in `ALL_HIER_CLASS_AE`.

Note:

This view is available starting with Oracle Database 19c, Release Update 19.13.
