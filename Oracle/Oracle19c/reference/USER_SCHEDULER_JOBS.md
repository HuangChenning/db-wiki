## 6.645 USER\_SCHEDULER\_JOBS

`USER_SCHEDULER_JOBS` displays information about the Scheduler jobs owned by the current user. Its columns (except for `OWNER`) are the same as those in `ALL_SCHEDULER_JOBS`.
