## 6.596 USER\_PARTIAL\_DROP\_TABS

`USER_PARTIAL_DROP_TABS` describes all tables in the schema of the current user that have partially completed `DROP COLUMN` operations. Its columns are the same as those in `ALL_PARTIAL_DROP_TABS`.
