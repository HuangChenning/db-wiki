## 6.527 USER\_JAVA\_RESOLVERS

`USER_JAVA_RESOLVERS` displays information about resolvers of the Java classes owned by the current user. Its columns (except for `OWNER`) are the same as those in `ALL_JAVA_RESOLVERS`.
