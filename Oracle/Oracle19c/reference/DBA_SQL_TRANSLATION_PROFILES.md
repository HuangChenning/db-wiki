## 5.367 DBA\_SQL\_TRANSLATION\_PROFILES

`DBA_SQL_TRANSLATION_PROFILES` describes all SQL translation profiles in the database. Its columns are the same as those in `ALL_SQL_TRANSLATION_PROFILES`.
