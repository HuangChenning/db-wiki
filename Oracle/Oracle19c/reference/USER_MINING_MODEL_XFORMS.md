## 6.552 USER\_MINING\_MODEL\_XFORMS

`USER_MINING_MODEL_XFORMS` describes the user-specified transformations embedded with the user's own models. Its columns (except `OWNER`) are the same as those in `ALL_MINING_MODEL_XFORMS`.
