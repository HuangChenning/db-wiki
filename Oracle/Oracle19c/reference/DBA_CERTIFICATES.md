## 4.193 DBA\_CERTIFICATES

`DBA_CERTIFICATES` displays all certificates in the database which are used for signature verification for blockchain tables. Its columns are the same as those in `ALL_CERTIFICATES`.

Note:

This view is available starting with Oracle Database 19c, Release Update 19.10.
