## 6.389 USER\_CODE\_ROLE\_PRIVS

`USER_CODE_ROLE_PRIVS` describes all the roles that are associated with program units owned by current user. Its columns (except for `OWNER`) are the same as those in `ALL_CODE_ROLE_PRIVS`.
