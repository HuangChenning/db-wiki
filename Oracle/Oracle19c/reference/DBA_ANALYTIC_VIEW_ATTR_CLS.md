## 4.53 DBA\_ANALYTIC\_VIEW\_ATTR\_CLS

`DBA_ANALYTIC_VIEW_ATTR_CLS` is identical to `DBA_ANALYTIC_VIEW_ATTR_CLASS`.

Note:

This view is available starting with Oracle Database 19c, Release Update 19.13.
