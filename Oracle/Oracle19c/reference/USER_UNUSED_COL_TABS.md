## 6.727 USER\_UNUSED\_COL\_TABS

`USER_UNUSED_COL_TABS` describes the tables owned by the current user that contain unused columns. Its columns (except for `OWNER`) are the same as those in `ALL_UNUSED_COL_TABS`.
