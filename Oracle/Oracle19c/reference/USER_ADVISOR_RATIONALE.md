## 6.278 USER\_ADVISOR\_RATIONALE

`USER_ADVISOR_RATIONALE` displays information about the rationales for the recommendations owned by the current user. Its columns (except for `OWNER`) are the same as those in `DBA_ADVISOR_RATIONALE`.
