## 4.146 DBA\_ATTRIBUTE\_DIM\_ORD\_ATRS

`DBA_ATTRIBUTE_DIM_ORD_ATRS` is identical to `DBA_ATTRIBUTE_DIM_ORDER_ATTRS`.

Note:

This view is available starting with Oracle Database 19c, Release Update 19.13.
