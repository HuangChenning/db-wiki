## 4.311 DBA\_GG\_AUTO\_CDR\_COLUMNS

`DBA_GG_AUTO_CDR_COLUMNS` provides details about all of the Oracle GoldenGate automatic conflict detection and resolution (CDR) columns in the database.

Its columns are the same as those in `ALL_GG_AUTO_CDR_COLUMNS`.
