## 6.668 USER\_SQLSET\_BINDS

`USER_SQLSET_BINDS` displays the bind values associated with the SQL tuning sets owned by the current user. Its columns (except for `SQLSET_OWNER`) are the same as those in `ALL_SQLSET_BINDS`.
