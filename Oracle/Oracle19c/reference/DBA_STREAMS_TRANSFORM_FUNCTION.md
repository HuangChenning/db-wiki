## 6.18 DBA\_STREAMS\_TRANSFORM\_FUNCTION

`DBA_STREAMS_TRANSFORM_FUNCTION` displays information about all rule-based transformation functions in the database. Its columns are the same as those in `ALL_STREAMS_TRANSFORM_FUNCTION`.
