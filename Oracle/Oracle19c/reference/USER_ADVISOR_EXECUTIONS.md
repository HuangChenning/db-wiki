## 6.271 USER\_ADVISOR\_EXECUTIONS

`USER_ADVISOR_EXECUTIONS` displays metadata information for tasks owned by the current user. Its columns (except for `OWNER`) are the same as those in `DBA_ADVISOR_EXECUTIONS`.
