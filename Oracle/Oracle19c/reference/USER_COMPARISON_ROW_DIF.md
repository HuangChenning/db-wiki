## 6.398 USER\_COMPARISON\_ROW\_DIF

`USER_COMPARISON_ROW_DIF` displays information about the differing rows in the comparison scans owned by the current user. Its columns are the same as those in `DBA_COMPARISON_ROW_DIF`.
