## 5.369 DBA\_SQLJ\_TYPE\_ATTRS

`DBA_SQLJ_TYPE_ATTRS` describes the attributes of all SQLJ object types in the database. Its columns are the same as those in `ALL_SQLJ_TYPE_ATTRS`.
