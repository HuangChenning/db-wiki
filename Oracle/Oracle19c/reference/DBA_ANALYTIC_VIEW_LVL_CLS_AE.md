## 4.82 DBA\_ANALYTIC\_VIEW\_LVL\_CLS\_AE

`DBA_ANALYTIC_VIEW_LVL_CLS_AE` describes the level classifications of all analytic views (across all editions) in the database. Its columns are the same as those in `ALL_ANALYTIC_VIEW_LVL_CLS_AE`.

Note:

This view is available starting with Oracle Database 19c, Release Update 19.13.
