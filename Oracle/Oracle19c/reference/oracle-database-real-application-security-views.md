## 2.6 Oracle Database Real Application Security Views

This manual describes these Oracle Database Real Application Security auditing views:

- [DBA\_XS\_AUDIT\_POLICY\_OPTIONS](DBA_XS_AUDIT_POLICY_OPTIONS.md)
- [DBA\_XS\_AUDIT\_TRAIL](DBA_XS_AUDIT_TRAIL.md)
- [DBA\_XS\_ENB\_AUDIT\_POLICIES](DBA_XS_ENB_AUDIT_POLICIES.md)

Descriptions of the other Oracle Database Real Application Security views are provided in [Oracle Database Real Application Security Administrator's and Developer's Guide](https://docs.oracle.com/pls/topic/lookup?ctx=en/database/oracle/oracle-database/19/refrn&id=DBFSG60000).

Note:

Oracle Database Real Application Security views include `_XS_` in the view name.
