## 6.341 USER\_ATTRIBUTE\_DIM\_ATTR\_CLASS

`USER_ATTRIBUTE_DIM_ATTR_CLASS` describes the attribute classifications of the attribute dimensions owned by the current user. Its columns (except for `OWNER`) are the same as those in `ALL_ATTRIBUTE_DIM_ATTR_CLASS`.
