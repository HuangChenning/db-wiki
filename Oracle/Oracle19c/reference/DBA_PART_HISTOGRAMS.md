## 5.229 DBA\_PART\_HISTOGRAMS

`DBA_PART_HISTOGRAMS` displays the histogram data (endpoints per histogram) for the histograms on all table partitions in the database. Its columns are the same as those in `ALL_PART_HISTOGRAMS`.
