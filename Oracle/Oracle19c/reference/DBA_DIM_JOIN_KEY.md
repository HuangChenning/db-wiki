## 4.261 DBA\_DIM\_JOIN\_KEY

`DBA_DIM_JOIN_KEY` describes all joins in the database between two dimension tables. The join is always specified between a parent dimension level column and a child column. This view's columns are the same as those in `ALL_DIM_JOIN_KEY`.
