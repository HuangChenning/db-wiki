## 5.246 DBA\_POLICIES

`DBA_POLICIES` describes all Oracle Virtual Private Database (VPD) security policies in the database. Its columns are the same as those in `ALL_POLICIES`.

A security policy is a list of security requirements and rules that regulate row level access to database objects.
