## 6.670 USER\_SQLSET\_REFERENCES

`USER_SQLSET_REFERENCES` describes whether or not the SQL tuning sets owned by the current user are active. Its columns (except for `SQLSET_OWNER`) are the same as those in `ALL_SQLSET_REFERENCES`.
