## 6.437 USER\_DIM\_JOIN\_KEY

`USER_DIM_JOIN_KEY` describes the join between two dimension tables owned by the current user. The join is always specified between a parent dimension level column and a child column. This view's columns are the same as those in `ALL_DIM_JOIN_KEY`.
