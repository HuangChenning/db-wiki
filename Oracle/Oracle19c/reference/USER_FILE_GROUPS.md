## 6.463 USER\_FILE\_GROUPS

`USER_FILE_GROUPS` shows top-level metadata about file groups owned by the current user. Its columns (except for `FILE_GROUP_OWNER`) are the same as those in `ALL_FILE_GROUPS`.
