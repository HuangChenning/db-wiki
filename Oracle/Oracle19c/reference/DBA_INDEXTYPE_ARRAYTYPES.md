## 5.115 DBA\_INDEXTYPE\_ARRAYTYPES

`DBA_INDEXTYPE_ARRAYTYPES` displays information about the array types specified by all indextypes in the database. Its columns are the same as those in `ALL_INDEXTYPE_ARRAYTYPES`.
