## 5.93 DBA\_HIVE\_TAB\_PARTITIONS

`DBA_HIVE_TAB_PARTITIONS` provides information about all Hive table partitions in the database. Its columns are the same as those in `ALL_HIVE_TAB_PARTITIONS`.
