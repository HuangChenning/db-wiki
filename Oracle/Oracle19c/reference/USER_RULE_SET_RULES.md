## 6.627 USER\_RULE\_SET\_RULES

`USER_RULE_SET_RULES` describes the rules in the rule sets owned by the current user. Its columns (except for `RULE_SET_OWNER`) are the same as those in `ALL_RULE_SET_RULES`.
