## 5.128 DBA\_JAVA\_IMPLEMENTS

`DBA_JAVA_IMPLEMENTS` describes interfaces implemented by all stored Java classes in the database. Its columns are the same as those in `ALL_JAVA_IMPLEMENTS`.
