## 4.284 DBA\_EVALUATION\_CONTEXT\_TABLES

`DBA_EVALUATION_CONTEXT_TABLES` describes the tables in all rule evaluation contexts in the database. Its columns are the same as those in `ALL_EVALUATION_CONTEXT_TABLES`.
