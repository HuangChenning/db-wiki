The `SDO_PC_PKG` package contains subprograms to support the use of point clouds in Spatial.

For a complete description of this package within the context of Oracle Spatial, see [`SDO_PC_PKG`](https://docs.oracle.com/pls/topic/lookup?ctx=en/database/oracle/oracle-database/19/arpls&id=SPATL172) in the *Oracle Spatial and Graph Developer’s Guide*.
