The `SDO_MIGRATE` package lets you upgrade geometry tables from previous releases of Oracle Spatial.

For a complete description of this package within the context of Oracle Spatial, see [`SDO_MIGRATE`](https://docs.oracle.com/pls/topic/lookup?ctx=en/database/oracle/oracle-database/19/arpls&id=SPATL160) in the *Oracle Spatial and Graph Developer’s Guide*.
