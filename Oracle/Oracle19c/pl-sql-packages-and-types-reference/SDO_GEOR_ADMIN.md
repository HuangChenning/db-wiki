The `SDO_GEOR_ADMIN` package contains subprograms for administrative operations related to GeoRaster.

For a complete description of this package within the context of Oracle Spatial, see [`SDO_GEOR_ADMIN`](https://docs.oracle.com/pls/topic/lookup?ctx=en/database/oracle/oracle-database/19/arpls&id=GEORS600) in the *Oracle Spatial and Graph GeoRaster Developer’s Guide*.
