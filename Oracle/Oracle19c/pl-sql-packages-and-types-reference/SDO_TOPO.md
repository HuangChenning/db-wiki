The `SDO_TOPO` package contains subprograms for creating and managing Oracle Spatial topologies.

For a complete description of this package within the context of Oracle Spatial, see [`SDO_TOPO`](https://docs.oracle.com/pls/topic/lookup?ctx=en/database/oracle/oracle-database/19/arpls&id=TOPOL200) in the *Oracle Spatial and Graph Topology Data Model and Network Data Model Graph Developer’s Guide*.
