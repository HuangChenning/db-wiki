The `SEM_APIS` package contains subprograms for working with the Resource Description Framework (RDF) and Web Ontology Language (OWL) in an Oracle database.

For a complete description of this package within the context of Oracle Database semantic technology support, see [`SEM_APIS`](https://docs.oracle.com/pls/topic/lookup?ctx=en/database/oracle/oracle-database/19/arpls&id=RDFRM500) in the *Oracle Spatial and Graph RDF Semantic Graph Developer’s Guide*.
