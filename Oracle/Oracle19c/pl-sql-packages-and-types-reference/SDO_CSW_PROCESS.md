The `SDO_CSW_PROCESS` package contains subprograms for various processing operations related to support for Catalog Services for the Web (CSW).

For a complete description of this package within the context of Oracle Spatial, see [`SDO_CSW_PROCESS`](https://docs.oracle.com/pls/topic/lookup?ctx=en/database/oracle/oracle-database/19/arpls&id=SPATL142) in the *Oracle Spatial and Graph Developer’s Guide.*.
