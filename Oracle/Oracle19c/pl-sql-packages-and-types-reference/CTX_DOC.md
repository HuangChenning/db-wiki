Note that you must install this package in order to use it.

For a complete description of this package within the context of Oracle Text, see [`CTX_DOC`](https://docs.oracle.com/pls/topic/lookup?ctx=en/database/oracle/oracle-database/19/arpls&id=CCREF2115) in the Oracle Text Reference.
