The `SDO_GEOR_RA` package provides an interface to the `SDO_GEOR_RA` package for performing raster algebra and analytic operations related to GeoRaster.

For a complete description of this package within the context of Oracle Spatial, see [`SDO_GEOR_RA`](https://docs.oracle.com/pls/topic/lookup?ctx=en/database/oracle/oracle-database/19/arpls&id=GEORS1226) in the *Oracle Spatial and Graph GeoRaster Developer’s Guide*.
