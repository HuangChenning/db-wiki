The `DBMS_WM` package provides an interface to Oracle Database Workspace Manager (often referred to as Workspace Manager).

For a complete description of this package, see [`DBMS_WM`](https://docs.oracle.com/pls/topic/lookup?ctx=en/database/oracle/oracle-database/19/arpls&id=ADWSM020) in the *Oracle Database Workspace Manager Developer’s Guide*.
