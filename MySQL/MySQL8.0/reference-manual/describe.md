### 15.8.1 DESCRIBE Statement

The `DESCRIBE` and [`EXPLAIN`](explain.md) statements are synonyms, used either to obtain information about table structure or query execution plans. For more information, see [Section 15.7.7.5, “SHOW COLUMNS Statement”](show-columns.md), and [Section 15.8.2, “EXPLAIN Statement”](explain.md).
