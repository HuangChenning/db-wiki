MySQL 8.0 Reference Manual Including MySQL NDB Cluster 8.0

This chapter discusses the rules for writing the following elements of [SQL](glossary.md) statements when using MySQL:

- Literal values such as strings and numbers
- Identifiers such as database, table, and column names
- Keywords and reserved words
- User-defined and system variables
- Expressions
- Query attributes
- Comments
