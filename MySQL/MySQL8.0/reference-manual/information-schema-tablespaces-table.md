### 28.3.40 The INFORMATION\_SCHEMA TABLESPACES Table

This table is unused. It is deprecated; expect it to be removed in a future MySQL release. Other `INFORMATION_SCHEMA` tables may provide related information:

- For `NDB`, the `INFORMATION_SCHEMA` [`FILES`](information-schema-files-table.md) table provides tablespace-related information.
- For `InnoDB`, the `INFORMATION_SCHEMA` [`INNODB_TABLESPACES`](information-schema-innodb-tablespaces-table.md) and [`INNODB_DATAFILES`](information-schema-innodb-datafiles-table.md) tables provide tablespace metadata.
