MySQL Enterprise Backup User's Guide (Version 8.0.46)

All MySQL Enterprise Backup functions are executed with the **mysqlbackup** client. It is used for performing different types of backup and restore operations, as well as other related tasks like backup compression, decompression, validation, and so on.

Use of the **mysqlbackup** client and the related commands are explained and illustrated throughout this manual. For detailed information on the **mysqlbackup** commands and command options, see [Part III, “ **mysqlbackup** Command Reference”](meb-command-reference.md).
