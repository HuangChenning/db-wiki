MySQL Enterprise Backup User's Guide (Version 9.7.0)

MySQL Enterprise Backup 9.7 is an Innovation release, which means it will have new features in addition to bug fixes, and it is supported until the next Innovation release comes out. MySQL Enterprise Backup 9.7 is recommended for use on production systems. With this new Innovation series, the existing 8.4 series will focus on security and bug fixes only.

For notes detailling the changes in MySQL Enterprise Backup 9.7, see [MySQL Enterprise Backup 9.7 Release Notes](https://docs.oracle.com/cd/E17952_01/mysql-enterprise-backup-9.7-relnotes-en/)
