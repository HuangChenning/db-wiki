### 15.4.2 SQL Statements for Controlling Replica Servers

This section discusses statements for managing replica servers. [Section 15.4.1, “SQL Statements for Controlling Source Servers”](replication-statements-source.md), discusses statements for managing source servers.

In addition to the statements described here, [`SHOW REPLICA       STATUS`](show-replica-status.md) and [`SHOW RELAYLOG       EVENTS`](show-relaylog-events.md) are also used with replicas. For information about these statements, see [Section 15.7.7.36, “SHOW REPLICA STATUS Statement”](show-replica-status.md), and [Section 15.7.7.35, “SHOW RELAYLOG EVENTS Statement”](show-relaylog-events.md).
