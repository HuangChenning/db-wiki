### 27.6.5 View Metadata

To obtain metadata about views:

- Query the [`VIEWS`](information-schema-views-table.md) table of the `INFORMATION_SCHEMA` database. See [Section 28.3.53, “The INFORMATION\_SCHEMA VIEWS Table”](information-schema-views-table.md).
- Use the [`SHOW CREATE VIEW`](show-create-view.md) statement. See [Section 15.7.7.15, “SHOW CREATE VIEW Statement”](show-create-view.md).
