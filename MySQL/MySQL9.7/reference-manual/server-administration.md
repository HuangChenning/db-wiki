MySQL 9.7 Reference Manual Including MySQL NDB Cluster 9.7

MySQL Server ([**mysqld**](mysqld.md)) is the main program that does most of the work in a MySQL installation. This chapter provides an overview of MySQL Server and covers general server administration:

- Server configuration
- The data directory, particularly the `mysql` system schema
- The server log files
- Management of multiple servers on a single machine

For additional information on administrative topics, see also:

- [Chapter 8, *Security*](security.md)
- [Chapter 9, *Backup and Recovery*](backup-and-recovery.md)
