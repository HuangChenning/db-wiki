### 25.2.5 Options, Variables, and Parameters Added, Deprecated or Removed in NDB 26.10

The next few sections contain information about `NDB` node configuration parameters and NDB-specific [**mysqld**](mysqld.md) options and variables that have been added to, deprecated in, or removed from NDB 26.10.

#### Parameters Introduced in NDB 26.10

No new node configuration parameters have been added in NDB 26.10.

#### Parameters Deprecated in NDB 26.10

No node configuration parameters have been deprecated in NDB 26.10.

#### Parameters Removed in NDB 26.10

No node configuration parameters have been removed in NDB 26.10.

#### Options and Variables Introduced in NDB 26.10

No new system variables, status variables, or server options have been added in NDB 26.10.

#### Options and Variables Deprecated in NDB 26.10

No system variables, status variables, or server options have been deprecated in NDB 26.10.

#### Options and Variables Removed in NDB 26.10

No system variables, status variables, or options have been removed in NDB 26.10.
