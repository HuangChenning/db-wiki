## Chapter 25 MySQL NDB Cluster 26.10

This chapter provides information about MySQL NDB Cluster, a high-availability, high-redundancy version of MySQL adapted for the distributed computing environment, as well as information specific to NDB Cluster 26.10 (NDB 26.7.0), based on version 26.10 of the NDB storage engine. See [Section 25.2.4, “What is New in MySQL NDB Cluster 26.10”](mysql-cluster-what-is-new.md), for information about differences in NDB 26.10 as compared to earlier releases. NDB 26.10 and higher are intended for use in production environments.

*NDB Cluster 7.6 and older release series are no longer supported or maintained*.
