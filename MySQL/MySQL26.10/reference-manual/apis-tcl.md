## 31.12 MySQL Tcl API

`MySQLtcl` is a simple API for accessing a MySQL database server from the [Tcl programming language](http://en.wikipedia.org/wiki/Tcl). It can be found at [http://www.xdobry.de/mysqltcl/](http://www.xdobry.de/mysqltcl/).
