### 15.1.16 CREATE FUNCTION Statement

The `CREATE FUNCTION` statement is used to create stored functions and loadable functions:

- For information about creating stored functions, see [Section 15.1.22, “CREATE PROCEDURE and CREATE FUNCTION Statements”](create-procedure.md).
- For information about creating loadable functions, see [Section 15.7.4.1, “CREATE FUNCTION Statement for Loadable Functions”](create-function-loadable.md).
