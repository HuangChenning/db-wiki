## 13.3 String Data Types

The string data types are [`CHAR`](char.md), [`VARCHAR`](char.md), [`BINARY`](binary-varbinary.md), [`VARBINARY`](binary-varbinary.md), [`BLOB`](blob.md), [`TEXT`](blob.md), [`ENUM`](enum.md), and [`SET`](set.md).

For information about storage requirements of the string data types, see [Section 13.7, “Data Type Storage Requirements”](storage-requirements.md).

For descriptions of functions that operate on string values, see [Section 14.8, “String Functions and Operators”](string-functions.md).
