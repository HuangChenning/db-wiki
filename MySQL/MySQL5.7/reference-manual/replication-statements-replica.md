### 13.4.2 SQL Statements for Controlling Replica Servers

This section discusses statements for managing replica servers. [Section 13.4.1, “SQL Statements for Controlling Replication Source Servers”](replication-statements-master.md), discusses statements for managing source servers.

In addition to the statements described here, [`SHOW SLAVE STATUS`](show-slave-status.md) and [`SHOW RELAYLOG EVENTS`](show-relaylog-events.md) are also used with replicas. For information about these statements, see [Section 13.7.5.34, “SHOW SLAVE STATUS Statement”](show-slave-status.md), and [Section 13.7.5.32, “SHOW RELAYLOG EVENTS Statement”](show-relaylog-events.md).
