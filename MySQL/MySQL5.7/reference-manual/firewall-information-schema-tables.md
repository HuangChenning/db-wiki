MySQL 5.7 Reference Manual Including MySQL NDB Cluster 7.5 and NDB Cluster 7.6

The following sections describe the `INFORMATION_SCHEMA` tables associated with MySQL Enterprise Firewall (see [Section 6.4.6, “MySQL Enterprise Firewall”](firewall.md)). They provide views into the firewall in-memory data cache. These tables are available only if the appropriate firewall plugins are enabled.
