### 13.8.1 DESCRIBE Statement

The `DESCRIBE` and [`EXPLAIN`](explain.md) statements are synonyms, used either to obtain information about table structure or query execution plans. For more information, see [Section 13.7.5.5, “SHOW COLUMNS Statement”](show-columns.md), and [Section 13.8.2, “EXPLAIN Statement”](explain.md).
