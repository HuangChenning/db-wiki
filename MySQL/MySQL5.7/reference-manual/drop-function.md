### 13.1.24 DROP FUNCTION Statement

The `DROP FUNCTION` statement is used to drop stored functions and loadable functions:

- For information about dropping stored functions, see [Section 13.1.27, “DROP PROCEDURE and DROP FUNCTION Statements”](drop-procedure.md).
- For information about dropping loadable functions, see [Section 13.7.3.2, “DROP FUNCTION Statement for Loadable Functions”](drop-function-loadable.md).
