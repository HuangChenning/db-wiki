### 24.3.26 The INFORMATION\_SCHEMA TABLESPACES Table

This table is unused. Other `INFORMATION_SCHEMA` tables may provide related information:

- For `NDB`, the `INFORMATION_SCHEMA` [`FILES`](information-schema-files-table.md) table provides tablespace-related information.
- For `InnoDB`, the `INFORMATION_SCHEMA` [`INNODB_SYS_TABLESPACES`](information-schema-innodb-sys-tablespaces-table.md) and [`INNODB_SYS_DATAFILES`](information-schema-innodb-sys-datafiles-table.md) tables provide tablespace metadata.
