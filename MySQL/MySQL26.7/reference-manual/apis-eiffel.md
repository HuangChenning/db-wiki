## 31.13 MySQL Eiffel Wrapper

Eiffel MySQL is an interface to the MySQL database server using the [Eiffel programming language](http://en.wikipedia.org/wiki/Eiffel_\(programming_language\)), written by Michael Ravits. It can be found at [http://efsa.sourceforge.net/archive/ravits/mysql.htm](http://efsa.sourceforge.net/archive/ravits/mysql.htm).
