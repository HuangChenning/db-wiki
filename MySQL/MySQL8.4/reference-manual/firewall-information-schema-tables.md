MySQL 8.4 Reference Manual Including MySQL NDB Cluster 8.4

The following sections describe the `INFORMATION_SCHEMA` tables associated with MySQL Enterprise Firewall (see [Section 8.4.7, “MySQL Enterprise Firewall”](firewall.md)). They provide views into the firewall in-memory data cache. These tables are available only if the appropriate firewall plugins are enabled.
