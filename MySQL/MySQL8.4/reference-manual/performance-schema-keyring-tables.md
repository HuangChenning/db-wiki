MySQL 8.4 Reference Manual Including MySQL NDB Cluster 8.4

### 29.12.18 Performance Schema Keyring Tables

The following sections describe the Performance Schema tables associated with the MySQL keyring (see [Section 8.4.4, “The MySQL Keyring”](keyring.md)). They provide information about keyring operation:

- [`keyring_component_status`](performance-schema-keyring-component-status-table.md): Information about the keyring component in use.
- [`keyring_keys`](performance-schema-keyring-keys-table.md): Metadata for keys in the MySQL keyring.
