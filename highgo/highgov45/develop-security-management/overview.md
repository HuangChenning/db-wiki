## 1\. 概述

## 1.1. 简介

本文档主要描述瀚高数据库的安全管理功能。安全性是评估一个数据库的重要指标。数据库的不安全因素包括非授权用户对数据库的恶意存取和破坏、数据库中的敏感数据被泄露、运行环境的安全性等。瀚高数据库通过采用用户标识和认证、访问控制和存储加密等技术对数据库系统进行安全控制，以防范各种不安全因素。

## 1.2. 安全功能介绍

瀚高数据库提供了丰富的安全管理功能。具体功能介绍详见下表。

表1 安全功能简介

| **安全功能** | **简介** |
| --- | --- |
| 用户标识与认证 | 每个用户有自己独有的标识及认证信息，可防止用户冒充 |
| 自主访问控制 | 使用权限控制用户可以访问的数据 |
| 强制访问控制 | 使用安全标记和级别控制用户可以访问的数据 |
| 审计 | 记录用户指定或全部的操作记录，可在事故发生后用于查找证据 |
| 存储加密 | 将数据库中的数据进行加密 |
| 通信加密 | 将网络上传输的数据进行加密 |
| 资源限制 | 对数据库可使用的资源进行设置，防止恶意的资源占用 |

## 1.3. 版本说明

本文档所述的安全管理功能全部适用于瀚高安全版数据库系统V4.5（以下简称HGDB-SEE V4.5）。在企业版和标准版数据库中仅有部分安全功能，将在介绍具体内容时指出。

该文档描述的功能始终与最新版安全版数据库的功能保持一致。某些功能在老版本中会有些许出入，具体以使用的实际结果为准。如有疑问，可拨打400-708-8006寻求技术协助。
