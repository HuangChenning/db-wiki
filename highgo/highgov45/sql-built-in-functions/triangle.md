## 三角函数

HGDB 提供以下三角函数：

| 函数（弧度） | 函数（角度） | 描述 |
| --- | --- | --- |
| acos(x) | acosd(x) | 反余弦 |
| asin(x) | asind(x) | 反正弦 |
| atan(x) | atand(x) | 反正切 |
| atan2(y,x) | atan2d(y,x) | y/x 的反正切 |
| cos(x) | cosd(x) | 余弦 |
| cot(x) | cotd(x) | 余切 |
| sin(x) | sind(x) | 正弦 |
| tan(x) | tand(x) | 正切 |
