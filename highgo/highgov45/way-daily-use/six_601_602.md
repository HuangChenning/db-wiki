## 企业版601和602使用row\_number()函数的区别

## 1、601 使用row\_number()函数查询出得结果为：

```
highgo=# select  row_number()  over(), * from  test ;
 row_number | id
------------+----
      1 |  1
(1 行记录)
```

查询的结果为row\_number 字段，可以将row\_number 使用别名替换  
例如：

```
highgo=# select  row_number()  over()  rownum , * from  test ;
 rownum | id
--------+----
      1 |  1
(1 行记录)
highgo=# select  row_number()  over() as rownum , * from  test ;
 rownum | id
--------+----
      1 |  1
(1 行记录)
```

## 2、602 使用row\_number 函数查询得结果，字段为rownum

```
highgo=# select  row_number()  over() , * from  test ;
 rownum | id
--------+----
      1 |  1
      2 |  2
(2 行记录)
```

也可以使用别名的形式去替换结果中的rownum。但是使用别名rownum时不能省略 as  
如 select row\_number() over() as rownum, \* from test; 这样是正确得  
但select row\_number() over() rownum, \* from test; 这样会有报错  
其他别名时无此报错。
