## 产品功能文档

## 1\. 基本功能

| 功能项 | 详细功能 |
| --- | --- |
| 分区管理 | 支持创建表分区，支持range、list、hash分区方式，并支持二级分区。 |
| 字符集 | 数据库支持UTF8、UTF8-mb4、GBK及GB18030字符集。 |
| 数据库对象 | 支持常用数据库对象，包括视图，序列，大对象。 |

## 2\. 安全性

| 功能项 | 详细功能 |
| --- | --- |
| 数据加密 | 内置数据加密（存储加密、传输加密），支持多种加密算法，对数据库文件进行透明加密，包括国密算法，如SM4。支持数据库服务器与客户端建立SSL加密连接，避免数据被窃听。 |
| 访问控制 | 访问控制（基于角色RBAC），支持针对表的具体列做访问控制，安全员可以配置列级访问控制策略。 |
| 备份恢复 | 支持数据备份与一键恢复，支持逻辑备份、物理备份功能，物理备份支持联机热备，支持全量备份、增量备份；支持基于时间点的备份恢复功能，当数据库发生故障时，支持基于时间点的恢复。 |
| 审计功能 | 所有数据库操作均被审计日志记录，无遗漏；审计日志包含操作时间、执行用户、客户端IP、SQL语句、操作结果等关键信息；可通过审计日志检索指定用户、指定时间范围的操作，满足合规审计追溯要求。 |
| 动态脱敏 | 支持对数据进行脱敏查看，根据安全管理员设置的安全规则或者安全策略，用户可以访问而且只能访问自己被授权的资源，未授权信息展现为脱敏后结果。安全员配置脱敏规则，数据访问者无感知。 |
| 三权分立 | 支持创建多种不同类型的权限账号和角色，例如安全管理员，审计管理员，数据管理员等。每个账号角色拥有不同的权限。安全员、审计员不能访问业务数据，数据管理员和普通用户也不能访问安全员、审计员的规则表，安全员和审计员也不能访问彼此的规则表。安全员配置安全相关的策略，审计员配置审计相关的规则。 |
| 权限管理 | 支持对不同账号分配不同角色，对不同角色分配不同权限，支持用户授权精细化管控，对应的用户仅能访问被授权的数据库及对象，未授权访问时返回权限拒绝错误。 |
| 额度管控 | 实例级资源额度管控：在创建数据库实例过程中，能够对CPU、内存进行额度管控。 |
| SQL防火墙 | 在实例中内置SQL防火墙，SQL防火墙通过匹配规则阻断非法SQL，以达到防注入、防攻击的效果。 |
| IP限制 | 支持配置IP白名单策略，仅白名单内的IP可连接数据库，非白名单IP发起的连接被拒绝。 |
| 身份标识和鉴别 | 支持口令鉴别，包括正确口令登录、错误口令拒绝等；支持配置口令复杂度规则，拒绝弱口令；支持登录失败锁定机制，包括达到失败次数阈值后账号锁定、解锁后恢复正常等；用户口令以加密形式存储，无明文泄露风险。 |

## 3\. 高可用

| 功能项 | 详细功能 |
| --- | --- |
| 主从复制 | 支持主从复制，支持一主多从，支持读写分离，一主多从的模式下，支持备机重做。 |
| 主备切换 | 在3节点架构下，对于主库故障可以自动进行同数据中心主备切换，不需要人工干预，确保RTO<30S，RPO=0，在主备切换的过程中，不影响异地灾备数据库的运行，且数据正常同步。 |
| 同步方式 | 主备同步模式可按需进行更改，可以设置为同步、异步等同步模式。 |
| 异地灾备 | 支持异地灾备，采用”主中心+异地灾备中心”架构，通过异步实现数据同步。 |

## 4\. 数据迁移

| 功能项 | 详细功能 |
| --- | --- |
| 迁移评估 | 在从MySQL数据库迁移数据之前，支持评估数据库的表、视图、触发器、约束、序列、函数等所有数据对象的兼容情况，并出具分析报告。 |
| 数据迁移 | 支持从MySQL中进行数据全量迁移（表结构、数据、索引）与增量迁移（同步新增/更新数据）。 |
| 数据校验 | 迁移过程支持数据一致性校验，支持数据内容对比，不一致数据自动标记。 |
| 可视化配置 | 支持迁移任务可视化配置（源库/目标库地址、迁移对象选择、大小写转换）。 |
| 异构同步工具 | 提供异构数据库同步工具，支持应答产品数据同步至主流异构数据库（如MySQL、分布式数据库等）。 |
| 不停机迁移 | 应答产品在替代现网MySQL数据库过程中，支持”全量+增量”迁移方式实现”零”停机柔性迁移，停机时间≤20min；迁移过程中保障业务连续性，无需改造应用业务，最大限度减少对业务的影响。 |
| 双轨并行 | 支持MySQL数据库和投标数据库之间建立数据同步”双轨并行”，具备配置链路双向复制的能力，目的为实现业务双轨并行，保障业务的稳健性，最终完成新旧系统转换。 |

## 5\. 管理与维护

| 功能项 | 详细功能 |
| --- | --- |
| 管理运维 | 需支持数据库图形化集中管控平台，主要功能包括：集群监控，故障诊断分析和上报，告警分析和上报，用户管理，查询监控和慢SQL查询，数据库性能分析报告。支持自定义告警，可定义异常的监控指标项、故障时间、告警方式等；告警包括但不限于免费对接企业微信，钉钉，邮件、短信、站内通知。 |
| 主备切换功能 | 集中管控平台支持在线进行数据库集群主备切换，切换完成时间小于20s。 |
| 在线重启 | 集中管控平台支持在线重启集群实例，输入用户密码或二次确认进行一键重启，并且支持查看操作日志。 |
| 在线部署 | 集中管控平台支持在线进行单实例部署、集群部署（主备部署）、一机多实例部署。 |
| 单实例多逻辑库部署 | 集中管控平台支持在线进行同实例多个逻辑库创建，逻辑库之间用户和数据强隔离。 |
| 操作系统监控 | 集中管控平台支持对部署节点进行CPU、内存、磁盘IO、文件系统、网络情况、系统运行状态指标监控，支持阈值告警。 |
| 数据库实例监控 | 集中管控平台支持对数据库状态、性能、系统负载的实时监测、跟踪统计，以及对数据库运行状况和性能的监测、提供会话、实时SQL、系统IO、事务信息，支持可视化数据库指标实时采样分析，包含对应的采样数量等。 |
| 数据库集群监控 | 集中管控平台满足集群同步状态的监控，包含同步复制状态、备库延时情况指标（主库日志写频率、备库接收延迟大小、备库落盘延迟大小、备库回放延迟大小等）。 |
| 数据库管理 | 集中管控平台支持数据库基本信息查看，包括：服务IP、服务端口、创建时间、版本号、高可用、实例数量、资源规格。 |
| 告警 | 集中管控平台支持对每个实例的监控告警发送站内、邮件、短信、企业微信通知；支持收集每个实例的监控告警，按照设置阈值发送监控告警通知；支持实时动态主动推送监控信息给管理员。 |
| 备份管理 | 集中管控平台支持通过图形化方式进行备份管理，对备份集进行查看、检查、还原、删除操作；支持通过图形化方式查看、筛选、删除备份任务，以及通过备份任务的状态（包括进行中、成功、失败、已过时等状态）进行查询；支持通过图形化方式设置自动备份任务，进行全量、增量备份以及备份时长阈值设置。支持对各类型的备份分别设置备份周期，时间间隔，对备份任务进行立即备份、暂停、停止操作。支持指定备份集的还原和基于时间点对备份文件进行恢复。 |
| 慢SQL查询分析 | 集中管控平台支持查看慢SQL核心指标，包括慢SQL的SQLID、SQL语句开始执行的时间、SQL语句结束执行的时间、SQL语句、SQL运行的数据库名称、client端的IP地址、执行SQL的用户名称、有效的DB时间、CPU时间、IO时间、SQL解析时间、存储过程执行时间、加锁等待时间、顺序扫描行数、SELECT返回的结果集函数。 |
| 在线补丁管理 | 集中管控平台支持在线进行补丁的新增、删除和应用，支持单个以及批量补丁升级和回退。 |
| 数据库智能管家 | 集中管控平台支持7×24小时实时数据库异常诊断、智能异常检测优化、全链路分析诊断、健康巡检等；对数据库环境无侵入，信息收集采用加密传输，保证数据安全；提供自助式智能服务，支持统一多维度实例批量管理。 |
| 节点管理 | 支持集群节点状态监控（在线/离线/故障）、节点新增/下线管理操作，管控总节点数量不设上限（≥450个），后续新增节点不再另行收费。 |
