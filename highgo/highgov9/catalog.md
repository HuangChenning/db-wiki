# 瀚高数据库 V9 文档目录

路径都相对于本文件所在的 `html-to-md` 目录。检索时先选定一栏，再打开对应的 `contents.md`。

## 参考指南

- `client-interface-guide/contents.md`：客户端接口指南。介绍 libpq、客户端大对象、ECPG 和信息模式等客户端编程接口。
- `server-programming-guide/contents.md`：服务器编程指南。介绍服务器扩展、触发器、规则、过程语言、后台工作进程和逻辑解码。
- `sql-command-quick-reference/contents.md`：SQL命令速查手册。提供 SQL 命令的集中速查资料。
- `sql-language-reference/contents.md`：SQL语言参考手册。系统介绍 SQL 语法、数据定义与操纵、查询、数据类型、函数、索引和并发控制。
- `server-application-reference/contents.md`：服务器应用参考手册。介绍瀚高数据库服务端应用和常用服务器工具。
- `client-application-reference/contents.md`：客户端应用参考手册。介绍瀚高数据库客户端应用和常用客户端工具。

## SQL开发指南

- `guide-built-in-functions/contents.md`：常用内置函数。介绍窗口、二进制串、几何、聚集、日期时间、数字和字符串等常用内置函数。
- `guide-triggers/contents.md`：触发器。介绍触发器的创建、管理、删除和事件触发器。
- `guide-stored-procedures-functions/contents.md`：存储过程&函数。介绍存储过程、函数、条件控制、循环和游标。
- `guide-dml/contents.md`：数据操纵DML。介绍 INSERT、UPDATE 和 DELETE 数据操纵语句。
- `guide-dql/contents.md`：数据查询DQL。介绍连接、子查询、组合查询、表达式、分组和排序。
- `guide-ddl/contents.md`：数据定义DDL。介绍 CREATE、ALTER、DROP 和约束等数据定义操作。
- `guide-dcl/contents.md`：数据控制DCL。介绍 GRANT 授权和 REVOKE 取消授权。
- `guide-data-types/contents.md`：数据类型。介绍布尔、二进制、货币、枚举、日期时间、数字、数组和字符等数据类型。

## 最佳实践

- `way-usage-practices/contents.md`：使用类。汇集列级透明加密和数据类型批量处理等使用实践。

## 常见问题

- `faq-migration-compatibility/contents.md`：迁移兼容类。汇集数据库迁移和多种兼容模式下的常见问题。
- `faq-database-usage/contents.md`：数据库使用类。汇集数据库功能、工具、备份、插件和日常使用问题。
- `faq-application-development/contents.md`：应用开发类。汇集 asyncpg、C++、Java、Python、Qt 等应用开发问题。

## 产品插件

- `extensions-list/contents.md`：插件列表。列出瀚高数据库 V9 提供的产品插件。

## 产品功能

- `product-ability-list/contents.md`：产品功能列表。列出瀚高数据库 V9 的产品功能。

## 兼容性

- `compatibility-oracle/contents.md`：Oracle兼容性。介绍 Oracle 模式的对象、数据类型、函数、语法和数据库特性兼容。
- `compatibility-mysql/contents.md`：MySQL兼容性。介绍 MySQL 模式的数据类型、语法、函数、参数和大小写兼容。

## 安全管理指南

- `safety-security-guide/contents.md`：安全指南。介绍身份鉴别、访问控制、加密、审计、脱敏和资源管理。
- `safety-administrator-guide/contents.md`：管理员指南。介绍数据库配置、角色、对象、监控、备份恢复、复制和日常维护。
