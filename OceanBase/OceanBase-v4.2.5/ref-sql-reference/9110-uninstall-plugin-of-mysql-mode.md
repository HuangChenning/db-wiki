# UNINSTALL PLUGIN

## 描述

该语句用于删除已安装的服务器插件。

## 语法

```sql
UNINSTALL PLUGIN plugin_name
```

  <h4>注意</h4>
  <p>当前版本仅支持该关键字语法，功能并不会实际生效。</p>
</main>
