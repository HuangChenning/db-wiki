# GTID_SUBTRACT()

## 描述

该函数用于返回集合中不属于子集的所有 GTID。

## 语法

```sql
GTID_SUBTRACT(set1,set2)
```

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>仅支持该关键字语法，功能不生效。</p>
</main>
