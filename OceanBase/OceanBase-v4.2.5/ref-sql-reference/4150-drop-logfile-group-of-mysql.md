# DROP LOGFILE GROUP

## 描述

该语句用来删除日志文件组。

## 语法

```sql
DROP LOGFILE GROUP logfile_group
    ENGINE [=] engine_name
```

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>仅支持该关键字语法，功能不生效。</p>
</main>
