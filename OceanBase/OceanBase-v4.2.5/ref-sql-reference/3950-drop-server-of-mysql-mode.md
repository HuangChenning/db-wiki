# DROP SERVER

## 描述

该语句用于删除服务器定义。

## 语法

```sql
DROP SERVER [ IF EXISTS ] server_name
```

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>仅支持该关键字语法，功能暂不生效。</p>
</main>
