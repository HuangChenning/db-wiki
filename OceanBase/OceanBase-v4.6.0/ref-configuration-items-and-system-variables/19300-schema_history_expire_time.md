# schema_history_expire_time

#### 说明

该配置项从 V1.4 版本开始引入。

#### 说明

该配置项从 V4.0.0 版本开始默认值由 30d 调整为 7d。

#### 说明

该配置项从 V4.0.0 版本开始取值范围由 \[1m, 365d\] 调整为 \[1m, 30d\]。
