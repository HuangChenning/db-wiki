# OB Cloud 云数据库读写分离最佳实践

#### 说明

当前仅阿里云，且 ODP 版本在 V4.3.1 及以上时，支持按副本进行选择。

#### 说明

如果使用只读列存副本功能，需要联系 OceanBase 技术支持把数据库代理升级到 ODP V4.3.2 及以上的版本。

#### 说明

只读副本的存储规格约束与集群实例约束相同。

#### 说明

- 当只读副本的节点数大于等于租户的 Unit 数，且只读副本各节点剩余资源大于等于租户资源时，才支持为对应租户开启只读副本。如集群实例是 3(1-1-1)或则 2(1-1)，则只读副本节点个数取值范围就是1， 如果集群实例9(3-3-3)，则只读副本节点个数取值范围是 1~3 若存在资源不足的情况，建议您先扩容只读副本节点规格，详情参考 [只读副本变配管理](../200.read-only-replica-management-of-cluster-tp/300.modify-configuration-of-cluster-read-only-replica-tp.md)。
- 建议租户只读副本的规格和集群只读副本的规格保持一致，若存在不一致的情况，可能会导致只读副本添加失败。

#### 说明

当前仅阿里云，且 ODC 版本在 V4.3.1 及以上时，支持按副本进行选择。

#### 说明

仅当 **读流量可访问副本** 选择 **按副本类型** 时可配置。

#### 说明

仅当 **读流量可访问副本** 选择 **按副本** 时可配置。

#### 说明

一个主集群实例下最多可以创建两个备实例。

#### 说明

- 备实例的计算和存储资源计费规则，详情参见 [实例计费说明](../../../100.product-introduction/700.price/100.tp-price/100.instance-billing.md)。

- 数据备份的费用根据备份空间收费，计费规则详见 [备份恢复费用](../../../100.product-introduction/700.price/100.tp-price/100.instance-billing.md)。

- 功能推广阶段，跨地域流量费用限时免费。

- 支付成功后，您可以在实例列表页面查看备实例的类型、系列、可用区、存储空间、付费方式、标签和状态等基本信息。
