由于应用的数据库访问通常是强读和弱读混合的情况，故一般使用前两种方式来指定 SQL 弱一致性读。

#### 注意

备集群的普通租户仅支持弱一致性读，如果发起强一致性读、写或者 DDL 操作，则会报错。

#### 说明

修改配置项的值时，如果希望应用到备集群的所有租户，可以指定 `TENANT=all`。
