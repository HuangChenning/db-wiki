# enable_ob_error_msg_style

<main id="notice" type='explain'>
<h4>说明</h4>
<p>该配置项从 V4.3.1 版本开始引入。</p>
</main>

## 功能描述

`enable_ob_error_msg_style` 用于选择 OBServer 的错误码类型。

## 权限要求

* 查询配置项

  `sys` 租户和所有用户租户均可以使用 `SHOW PARAMETERS` 语句或视图 `GV$OB_PARAMETERS` 查询该配置项。

* 修改配置项

  仅 `sys` 租户可以修改该配置项，用户租户不能修改该配置项。

## 属性说明

|      **属性**      |                          **描述**                            |
|------------------|------------------------------------------------------------------|
| 参数类型             | Bool                                                         |
| 默认值              | True                                                            |
| 取值范围             | <ul><li>True：使用 OBE-xx 格式错误码。 </li><li>False：使用 ORA-xx 格式格式错误码 </li></ul>     |
| 是否重启 OBServer 节点生效 | 否                                                      |

## 配置示例

设置使用 OBE-xx 格式错误码。

```shell
obclient> ALTER SYSTEM SET enable_ob_error_msg_style = True;
```
