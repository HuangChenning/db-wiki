# oceanbase.DBA_OB_SYS_VARIABLE_HISTORY

<main id="notice" type='explain'>
<h4>说明</h4>
<p>该视图从 V5.0.1 版本开始引入。</p>
</main>

## 功能描述

视图 `DBA_OB_SYS_VARIABLE_HISTORY` 用于展示当前租户的所有 Global 级别系统变量的修改历史。

## 字段说明

| 字段名称     | 类型           | 是否可以为 NULL | 描述 |
|-------------|----------------|----------------|------|
| NAME        | varchar(128)   | NO   | 变量名     |
| VALUE       | varchar(65536) | YES  | 变量值     |
| MODIFY_TIME | timestamp(6)   | NO   | 变量值的修改时间     |

## 查询示例

用户租户查询本租户的系统变量 `ob_query_timeout` Global 级别变量值的修改历史。

```shell
obclient(root@mysql001)[oceanbase]> SELECT * FROM oceanbase.DBA_OB_SYS_VARIABLE_HISTORY WHERE NAME = 'ob_query_timeout';
```

查询结果如下：

```shell
+------------------+----------+----------------------------+
| NAME             | VALUE    | MODIFY_TIME                |
+------------------+----------+----------------------------+
| ob_query_timeout | 10000000 | 2026-06-24 17:34:34.323366 |
+------------------+----------+----------------------------+
1 row in set
```
