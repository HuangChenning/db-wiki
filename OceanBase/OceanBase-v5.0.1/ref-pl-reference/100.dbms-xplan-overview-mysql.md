# DBMS_XPLAN 概述

`DBMS_XPLAN` 系统包提供了逻辑计划管理相关的功能，包括逻辑计划优化追踪等。

## DBMS_XPLAN 权限说明

拥有执行 PL SQL 权限的用户可以使用该功能。

## DBMS_XPLAN 子程序概览

下表列出了 OceanBase 数据库当前版本所支持的 `DBMS_XPLAN` 子程序和简要描述。

| 子程序 | 描述 |
| --- | --- |
| [DISPLAY_ACTIVE_SESSION_PLAN](200.display-active-session-plan-of-mysql-mode.md)| 用于展示指定 Session 的实时计划详情。|
| [DISPLAY_CURSOR](300.display-cursor-of-mysql-mode.md) | 用于展示已执行的查询计划详情。 |
| [DISPLAY](400.display-of-mysql-mode.md) | 查询并格式化历史的 `EXPLAIN` 计划。 |
| [DISABLE_OPT_TRACE](500.disable-opt-trace-mysql.md) | 关闭当前 Session 的优化器全链路追踪功能。 |
| [DISPLAY_SQL_PLAN_BASELINE](600.display-sql-plan-baseline-of-mysql-mode.md) | 查看 SPM 的基线计划。 |
| [ENABLE_OPT_TRACE](800.enable-opt-trace-mysql.md) | 开启当前 Session 的优化器全链路追踪。 |
| [SET_OPT_TRACE_PARAMETER](1000.set-opt-trace-parameter-mysql.md) | 修改当前 Session 的优化器全链路追踪的参数。 |
