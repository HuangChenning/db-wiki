# OB_CLIENT_ID_TRACE_DISABLE

`OB_CLIENT_ID_TRACE_DISABLE` 用于关闭 client_identifier 级别全链路追踪。

<main id="notice" >
  <h4>功能适用性</h4>
  <p>该内容仅适用于 OceanBase 数据库企业版。</p>
</main>

## 语法

```sql
DBMS_MONITOR.OB_CLIENT_ID_TRACE_DISABLE(client_id IN  VARCHAR2);
```

## 参数解释

| **参数**      | **解释**                            |
|--------------|-------------------------------------|
| client_id    | 关闭全链路追踪的 `client_id`。       |
