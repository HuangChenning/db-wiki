# 大对象数据类型

大对象数据类型（Large Object，LOB），用来存储大型和非结构化数据，例如文本、图像、视频和空间数据等。大对象数据类型包括 `BLOB` 和 `CLOB`。

  <main id="notice" >
    <h4>功能适用性</h4>
    <p>该内容仅适用于 OceanBase 数据库企业版。OceanBase 数据库社区版暂不支持。</p>
  </main>

## BLOB

用于存储数据库中的大型二进制对象，可以将其视为没有字符集语义的位流，比如图像，视频等。

## CLOB

用于存储单字节和多字节字符数据。支持固定宽度和可变宽度字符集，且都使用数据库字符集。

详细信息请参见 [大对象数据类型](../ref-sql-reference/100.data-types-of-large-objects-of-oracle-mode.md)。
