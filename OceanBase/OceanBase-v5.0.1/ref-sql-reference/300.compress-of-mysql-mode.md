# COMPRESS

## 声明

```sql
COMPRESS(str)
```

## 说明

压缩字符串并将结果作为二进制字符串返回。可以使用 [UNCOMPRESS](1100.uncompress-of-mysql-mode.md) 函数对结果进行解压。

## 示例

```sql
obclient> SELECT COMPRESS('abc');
+-----------------+
| COMPRESS('abc') |
+-----------------+
|    x?KLJ M'  |
+-----------------+
1 row in set
```
