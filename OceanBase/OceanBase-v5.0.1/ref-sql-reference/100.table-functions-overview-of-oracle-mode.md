# TABLE FUNCTION 概述

## 描述

Table Function（表函数）用于将 JSON、XML 或外部文件等数据源转换为可查询的关系行集。

Oracle 模式下常见的表函数入口包括：

- `JSON_TABLE(...)`
- `XMLTABLE(...)`
- `FILES(...)`

## 语法特点

### 常见入口

- `JSON_TABLE(...)`
- `XMLTABLE(...)`
- `FILES(...)`

### XMLTABLE 关键能力

- 支持 `XMLNAMESPACES` 命名空间声明
- 支持 `PASSING` 传入 XML 数据
- 支持 `COLUMNS` 子句定义输出列
- 要求提供 XQuery 字面量

### 别名

Oracle 模式下可不显式指定别名。未指定时系统可生成名称。

## 返回表结构的函数

| 名称 | 用途 |
|------|------|
| JSON_TABLE | 将 JSON 文档映射为关系行列 |
| XMLTABLE | 将 XML 文档映射为关系行列 |
| FILES | 从外部文件生成可查询行集 |
