# 字面量概述

字面量（Literals）用于表达一个固定的数值，与常量值是同义词。许多函数和 SQL 语句都需要指定字面量，字面量也可以作为表达式和条件的一部分。

OceanBase 数据库支持以下字面量：

* [文本字面量](200.literal-value-of-text-of-oracle-mode.md)

* [数值字面量](300.numeric-literal-of-oracle-mode.md)

* [日期字面量](100.date-literal-of-oracle-mode.md)

* [时间戳字面量](200.timestamp-literal-of-oracle-mode.md)

* [间隔字面量](500.interval-literal-of-oracle-mode.md)
