# 数据类型比较规则概述

数据类型比较规则规定了 OceanBase 数据库如何比较每种数据类型的值。本章节主要介绍数值、日期值和字符值的比较规则，以及数据类型优先级和转换规则等。

OceanBase 数据库支持如下数据类型比较规则：

* [数值比较规则](200.numeric-value-of-oracle-mode.md)

* [日期值比较规则](300.date-value-of-oracle-mode.md)

* [字符值比较规则](400.character-value-of-oracle-mode.md)

* [数据类型优先级](500.data-type-priority-of-oracle-mode.md)

* [数据类型转换](600.data-type-conversion-of-oracle-mode.md)
