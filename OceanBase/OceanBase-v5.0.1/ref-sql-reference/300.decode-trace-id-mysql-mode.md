# DECODE_TRACE_ID

## 声明

```sql
DECODE_TRACE_ID()
```

## 说明

`DECODE_TRACE_ID()` 函数用于解析 trace_id，返回 SQL 请求来源服务器的 IP 和 PORT。您也可以通过视图 [GV$OB_SQL_AUDIT](../ref-system-views/3500.gv-ob_sql_audit-of-mysql-mode.md) 查看相关信息。

## 示例

```sql
obclient [(none)]> SELECT DECODE_TRACE_ID(LAST_TRACE_ID());
```

返回结果如下：

```shell
+----------------------------------+
| DECODE_TRACE_ID(LAST_TRACE_ID()) |
+----------------------------------+
| xxx.xx.xxx.xx1:2882              |
+----------------------------------+
1 row in set
```
