# DROP DATABASE LINK

## 描述

删除已创建的数据库链接（即 `dblink`）。

>**说明**
>
>要删除已创建的数据库链接，您必须具有 `DROP DATABASE LINK` 系统权限。

## 语法

```sql
DROP DATABASE LINK dblink_name
```

## 参数说明

`dblink_name` 为要删除的数据库链接的名称。

## 示例

```sql
obclient> DROP DATABASE LINK ob_dblink;
```
