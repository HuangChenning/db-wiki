# 性能监控

#### 说明

仅首次登录需要输入 Prometheus 的地址、用户名、密码。若暂未部署，建议使用 obd 安装部署。

#### 说明

通过入口一即从 **租户管理** 页面进入 **性能监控** 页面，只能查看当前租户的监控信息。
