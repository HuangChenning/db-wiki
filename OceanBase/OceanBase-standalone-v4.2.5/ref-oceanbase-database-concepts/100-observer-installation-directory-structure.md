# OBServer 节点安装目录结构

#### 说明

- `datafile_size` 用于设置数据文件的大小。

- `datafile_disk_percentage` 表示占用 `data_dir` 所在磁盘（ `data_dir` 所在磁盘将被 OceanBase 数据库系统初始化用于存储数据）总空间的百分比。

有关两个配置项的详细介绍，参见《OceanBase 数据库参考指南》中的 **系统配置项** 章节。
