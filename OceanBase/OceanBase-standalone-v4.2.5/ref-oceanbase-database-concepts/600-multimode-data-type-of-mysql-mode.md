# 多模数据类型

#### 注意

- MySQL 模式下多模数据类型在当前版本只支持 GIS 和 JSON。
- MySQL 模式下，基于 JSON 的虚拟生成函数，可以在任意 JSON 内的子元素上建立二级索引。
