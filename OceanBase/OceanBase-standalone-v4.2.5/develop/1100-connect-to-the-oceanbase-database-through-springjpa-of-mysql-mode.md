# SpringJPA

#### 注意

在 Oracle 模式下需要配置 `spring.jpa.properties.hibernate.dialect = org.hibernate.dialect.Oracle12cDialect`，如果是在 MySQL 模式下，该值应更改为 `org.hibernate.dialect.MySQL5Dialect`，或者不配置本行。
