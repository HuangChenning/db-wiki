# SqlSugar

#### 说明

本文中给出的操作步骤是在 Windows 环境下使用 Visual Studio Community 2019 编译和运行该项目的步骤。如果您使用的是其他操作系统环境或编译器，那么操作步骤可能会略有不同。

#### 说明

填写完数据库连接信息，您可以先点击 **Test DSN** 查看数据源是否可以连接成功。

#### 注意

在运行程序时，请将 `your_dsn` 替换为您在 **步骤一** 中创建的数据源名称。
