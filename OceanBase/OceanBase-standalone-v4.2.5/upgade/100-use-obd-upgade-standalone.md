# 使用 obd 升级 OceanBase 集中式数据库

#### 注意

不要和之前部署的目录在一起，避免新旧安装包混合在一起。

#### 注意

执行 `bash bin/uninstall_obd.sh` 不需要加 sudo 。

#### 注意

执行 `bash bin/uninstall_obd.sh` 不需要加 sudo 。

#### 注意

执行 `bash bin/install_obd.sh` 不需要加 sudo 。
