# 更改表

#### 注意

修改表的 Collation 和字符集设置仅影响后续添加的字符类型的列的数据保存方式，已有字符类型的列的数据保存方式不会被修改。

#### 说明

对于 OceanBase 数据库 V4.2.5 版本，从 V4.2.5 BP5 版本开始支持清除废弃列。
