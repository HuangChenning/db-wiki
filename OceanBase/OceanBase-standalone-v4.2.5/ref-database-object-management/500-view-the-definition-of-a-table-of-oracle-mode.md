# 查看表的定义

表创建成功后，您可以通过 SQL 语句来查看表的定义。

使用以下语句来查看表的定义：

``` sql
obclient> SELECT dbms_metadata.get_ddl( 'TABLE', 'TEST', 'SYS' ) FROM DUAL; 
```

返回结果如下：

``` sql
+------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| DBMS_METADATA.GET_DDL('TABLE','TEST','SYS')                                                                                                                                                                                                                                                                      |
+------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| CREATE TABLE "TEST" (
  "ID" NUMBER(*,0) NOT NULL ENABLE,
  "NAME" VARCHAR2(50) DEFAULT NULL,
  "GMT_CREATE" TIMESTAMP(6) DEFAULT current_timestamp NOT NULL ENABLE,
  PRIMARY KEY ("ID")
) COMPRESS FOR ARCHIVE REPLICA_NUM = 1 BLOCK_SIZE = 16384 USE_BLOOM_FILTER = FALSE TABLET_SIZE = 134217728 PCTFREE = 0 |
+------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
1 row in set
```

当想要查看某个表或者是表空间的 DDL 的时候，可以利用 `dbms_metadata.get_ddl` 这个包来查看，`TABLE` 字段代表 DDL 语句的对象类型为表，`TEST` 字段代表表名，`SYS` 代表查看 `SYS` 用户下的表。
