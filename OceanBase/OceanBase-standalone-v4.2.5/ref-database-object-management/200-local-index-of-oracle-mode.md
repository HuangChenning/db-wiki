# 局部索引

#### 注意

- 在 Oracle 模式中，如果索引属性关键字没有指定，那么默认的索引属性是 GLOBAL 属性，即创建的索引是全局索引，并且索引表只有一个分区。

- 唯一索引必须包括表分区函数中的所有列。
