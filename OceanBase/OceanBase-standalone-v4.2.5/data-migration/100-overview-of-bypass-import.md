# 旁路导入概述

#### 说明

对于 OceanBase 数据库 V4.2.5 版本，旁路导入从 V4.2.5 BP1 版本开始支持将 OceanBase 数据库 V1.4x/V3.x 版本的备份数据（V1.4x 是逻辑备份，V3.x 是物理备份）直接导入到 OceanBase 数据库 V4.x 版本中，从 V4.2.5 BP4 版本开始支持将 OceanBase 数据库 V2.x 版本的备份数据（逻辑或物理备份）直接导入到 OceanBase 数据库 V4.x 版本中。
