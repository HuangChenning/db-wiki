# OceanBase 集中式版 V4.2.5 文档目录

路径都相对于本文件所在的 `OceanBase-standalone-v4.2.5` 目录。检索时先选定一栏，再打开对应的 `contents.md`。

## 实践教程与附录

- `release-notes/contents.md`：版本发布记录。各版本 Release Notes、新特性发布与兼容性变更记录。

## 快速入门与概述

- `learn-more-about-oceanbase/contents.md`：集中式版简介。OceanBase 架构理念、版本差异、核心特性与系统组成。
- `quickstart/contents.md`：快速上手集中式版。快速体验部署、SQL 基础入门与示例应用开发。

## 应用开发与生态

- `develop/contents.md`：应用开发。Java、Python、C/C++、Go 等多语言开发实践与规范。

## 部署与生命周期

- `deploy/contents.md`：部署集中式版。单节点、分布式集群、容器化及容灾架构安装部署指南。
- `upgade/contents.md`：升级集中式版。跨版本与小版本升级准备、热升级与滚动升级操作指引。
- `data-migration/contents.md`：数据迁移。使用 OMS、DataX 等工具进行数据评估、迁移与实时同步。
- `deploy-practices/contents.md`：集中式版部署实践。使用 OBD 交互式、白屏及配置文件部署实战指南。

## 数据库运维与管理

- `manage/contents.md`：管理数据库。租户管理、资源隔离、集群运维、备份恢复与高可用管控。
- `ref-system-management/contents.md`：系统管理。集群状态监控、节点运维、日常巡检与核心管理操作。
- `ref-database-object-management/contents.md`：数据库对象管理。表、索引、分区、视图、序列等对象的生命周期与维护。

## 系统原理与调优

- `ref-oceanbase-database-concepts/contents.md`：系统原理。分布式架构、LSM-Tree、Paxos 协议与事务引擎底层原理。
- `ref-performance-tuning-guide/contents.md`：性能调优。执行计划分析、SQL 优化、系统参数调优与高并发调优。
- `performance-test/contents.md`：性能测试。基准性能压测、TPC-C 与 Sysbench 测试指引。

## 工具、平台与插件

- `ref-obshell/contents.md`：obshell。obshell 运维管理服务与 RESTful API 使用指南。
- `common-tools/contents.md`：常用工具。OBD、OBClient 等常用工具集使用说明。

## 系统参考与配置

- `ref-overview/contents.md`：参考指南概览。集中式版常用参数、视图与基础技术规格参考速查。
