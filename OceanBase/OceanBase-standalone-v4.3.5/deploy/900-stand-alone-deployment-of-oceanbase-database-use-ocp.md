# 平台运维部署方案

#### 说明

部署 OceanBase 集中式数据库需要使用 V4.3.5 BP2 及以上版本的 OCP。本文以 OCP V4.3.5 BP2 版本为例提供操作指导，不同 OCP 版本的操作界面可能不同，请以实际界面为准。

#### 注意

轻量运维部署方案和平台运维部署方案使用的安装包不同，在获取安装包的时候，务必确保获取到相应的安装包。

#### 说明

可以通过 [OceanBase 官网软件下载中心](https://www.oceanbase.com/softwarecenter-standalone)获取集中式数据库安装包。该安装包配置有试用版许可证（非生产用途），有效期为 180 天，仅供您进行学习、测试或适配使用，不提供技术支持及 SLA 保障，不得用于营利性、商业性或生产目的。试用许可证过期后，您将无法继续使用数据库功能。如果您需要将软件用于生产环境，或营利性、商业性目的，并需要专业的技术支持保障，请联系 OceanBase 获取商业版许可。

#### 说明

部署 OceanBase 集中式数据库推荐使用 admin 用户，也可以使用其他用户(不推荐 root 用户)。但是要求用户具备 sudo 权限和作为数据库相关目录的所有者。

#### 说明

如果已经部署了 OCP V4.3.5-20250326153512 及以上版本，则不需要再部署 OCP，可以直接[使用 OCP 部署集中式数据库](#使用-ocp-部署集中式数据库-1)。

#### 说明

目前 OceanBase 未提供集中式数据库安装包的下载途径，需联系 OceanBase 获取对应的安装包。

#### 注意

执行 `obd web` 命令不需要加 sudo 。

#### 说明

为避免操作系统用户冲突，建议为 MetaDB 及 OCP 配置独立的操作系统用户。

#### 注意

主机地址不能配置为 `127.0.0.1`。

#### 注意

OBServer 节点不能配置为 `127.0.0.1`。

#### 说明

您可通过在 **更多配置** 中设置 `scenario` 配置项来设置集群负载类型，未配置的情况下默认 `scenario` 为 `htap`。

#### 注意

需保证 **软件路径**、**数据路径** 及 **日志路径** 所在目录的磁盘空间充足，否则将部署失败。

#### 注意

节点 IP 不能配置为 `127.0.0.1`。

#### 说明

若本地仓库中存在 OceanBase 数据库和 OBProxy 的安装包，obd 会在部署 OCP 过程中自动识别并上传最新版本的 OceanBase 数据库和 OBProxy 安装包到该目录下。

#### 说明

部署 OCP 的机器需参照 OCP 的安装规划要求进行，详细介绍可参见《云平台 OCP》中 [安装规划](https://www.oceanbase.com/docs/common-ocp-1000000002381284) 章节。

#### 说明

部署成功后，您可参照 《云平台 OCP》 中 [部署后检查](https://www.oceanbase.com/docs/common-ocp-1000000002381077) 一文检查部署的 OCP 是否可以正常使用。
