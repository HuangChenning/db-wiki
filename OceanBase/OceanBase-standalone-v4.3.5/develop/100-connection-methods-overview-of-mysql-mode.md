# 连接方式概述

#### 说明

LibOBClient 生成的 so 文件为 `libobclient.so`（对应 MySQL 的 `libmysqlclient.so`），OceanBase 数据库安装后的命令行工具是 OBClient（对应 MySQL 的命令行工具）。
