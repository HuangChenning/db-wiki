# 升级版本

#### 说明

- 对于 OceanBase 集中式数据库 V4.2.5.x 系列版本，自 V4.2.5 BP6 hotfix1 起支持升级 OceanBase 集中式数据库到更新版本。

- 对于 OceanBase 集中式数据库 V4.3.5.x 系列版本，自 V4.3.5 BP3 hotfix4 起支持升级 OceanBase 集中式数据库到更新版本。
