# 性能监控

#### 说明

仅首次登录 **性能监控** 页面需输入 Prometheus 地址、用户名、密码等信息。

#### 说明

obshell Dashboard 自 V4.4.1 起支持对监控指标进行编辑操作，您可访问 [阿里云镜像站](https://mirrors.aliyun.com/oceanbase/community/stable/el/?spm=a2c6h.25603864.0.0.1f4328b3mIcuek) 获取相应安装包，使用 obshell Dashboard 直接进行升级，升级操作详参：[升级 obshell](500-ob-dashboard-obshell-upgrade.md)。

#### 说明

通过入口一即从 **租户管理** 页面进入 **性能监控** 页面，只能查看当前租户的监控信息。

#### 说明

obshell Dashboard 自 V4.4.1 起支持对监控指标进行编辑操作，您可访问 [阿里云镜像站](https://mirrors.aliyun.com/oceanbase/community/stable/el/7/x86_64/?spm=a2c6h.25603864.0.0.23db5d3eN9iVGQ) 获取相应安装包，使用 obshell Dashboard 直接进行升级，升级操作详参：[升级 obshell](500-ob-dashboard-obshell-upgrade.md)。
