# 立即备份

#### 说明

单击 **测试并配置** 后，obshell 会创建对应的测试并配置存储配置的任务，可单击 **查看任务** 跳转查看任务。正常情况下，该任务在数秒内即可成功完成，如果失败，请前往任务中心查看并修正错误原因。待任务完成后才能单击 **立即备份** 执行备份。

#### 说明

物理备份下，增量备份之前必须有一次全量的数据备份。
