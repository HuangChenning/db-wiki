# 参数管理

#### 说明

通过 **集群管理** 页面查看到的参数均为 OceanBase 集群的配置项（集群级和租户级），通过 **租户管理** 页面查看到的参数为 OceanBase 集群的租户级配置项和 Global 系统变量。
