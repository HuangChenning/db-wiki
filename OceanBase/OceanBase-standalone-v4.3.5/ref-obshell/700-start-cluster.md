# 启动集群

#### 说明

对于 OceanBase 集中式数据库，只存在一个 Zone，且 Zone 下只存在一个 OBServer 节点。因此，`type` 配置为 `GLOBAL`、`ZONE` 或 `SERVER` 时，实现效果均一致。
