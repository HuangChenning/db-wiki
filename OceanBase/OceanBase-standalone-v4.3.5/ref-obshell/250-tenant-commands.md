# obshell 租户命令组

#### 说明

仅在 OceanBase 集群为 V4.3.0 或之后版本时，支持使用该选项设置租户负载类型。

#### 说明

该选项与 `--old_password`/`--new_password` 互斥，不可同时指定，同时指定时会报错。
