# 集中式版配套工具

OceanBase 集中式数据库有完善的配套工具体系，可以满足您安装部署、数据迁移、运维管理、诊断自治、数据开发等全生命周期的数据库使用诉求。

| 工具 | 介绍 | 配套版本 | 了解更多 |
|----|----|----|----|
| obd | OceanBase Deployer，是 OceanBase 数据库的安装部署工具，支持命令行和白屏界面部署，简化集群配置流程。同时提供包管理、压测及集群管理等运维能力。 | V3.2.0 及以上版本 | [obd 文档](https://www.oceanbase.com/docs/obd-cn) |
| OBClient | 命令行交互式查询工具，支持 MySQL 和 Oracle 租户的连接，需单独安装。 | V2.2.10 及以上版本 |  |
| OCP | OceanBase 云平台，提供集群和租户全生命周期管理、资源管理，降低 IT 运维成本。 | V4.3.5 BP2（V4.3.5-20250326153512）及以上版本 | [OCP 文档](https://www.oceanbase.com/docs/ocp) |
| OMA | 数据库迁移评估工具，提供兼容性、性能评估，及迁移改造建议。 | V4.2.4 及以上版本 | [OMA 文档](https://www.oceanbase.com/docs/oma-doc-cn) |
| OMS | 实时数据迁移服务，支持同构/异构数据库与 OceanBase 之间的数据同步与迁移。 | V4.2.5 及以上版本 | [OMS 文档](https://www.oceanbase.com/docs/oms-doc-cn) |
| 导数工具（OBLOADER/OBDUMPER） | 专为 OceanBase 设计的数据导入导出工具，支持结构与数据迁移及 ETL 处理。 | V4.3.3 及以上版本 | [导数工具文档](https://www.oceanbase.com/docs/oceanbase-dumper-loader) |
| ODC | 图形化开发工具（桌面版/Web版），提供数据库开发、变更管控及团队协作能力。 | V4.3.4 及以上版本 | [ODC 文档](https://www.oceanbase.com/docs/odc) |
| OceanBase Connector/J | JDBC 驱动程序，实现 Java 应用与 OceanBase 数据库的连接。 | V2.4.14 及以上版本 | [OceanBase Connector/J 文档](https://www.oceanbase.com/docs/oceanbase-connector-j-cn) |
| OceanBase OCI 驱动程序 | 是与 Oracle OCI 兼容的 OceanBase C 语言接口调用工具，它提供了与 Oracle OCI 完全兼容的功能特性 | V2.0.10 及以上版本 | [OceanBase OCI 文档](https://www.oceanbase.com/docs/obci-cn) |
