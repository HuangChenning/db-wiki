# 创建索引

#### 注意

多值索引可以定义为唯一索引。如果将其定义为唯一索引，尝试插入已存在于多值索引中的值会返回重复键错误。如果已经存在重复值，尝试添加唯一的多值索引会失败。

#### 注意

当前版本只支持创建局部全文索引。

#### 说明

对于 OceanBase 数据库 V4.3.5 版本，从 V4.3.5 BP2 版本开始支持 `NGRAM2` 分词器。

#### 说明

对于 OceanBase 数据库 V4.3.5 版本，从 V4.3.5 BP1 版本开始支持 `IK` 分词器。

#### 说明

对于 OceanBase 数据库 V4.3.5 版本，从 V4.3.5 BP1 版本开始支持指定分词器属性（`PARSER_PROPERTIES`）。
