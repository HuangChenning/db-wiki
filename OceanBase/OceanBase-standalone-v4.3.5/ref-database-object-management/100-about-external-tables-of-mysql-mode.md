# 关于外表与外部文件

#### 说明

无元数据场景下，除 `FILES()` 外，还可使用 `SELECT` 中的 Location URL 形式直接读文件，详见 [URL 外表](../obap/300-url-external-table.md)。文件格式（`FORMAT`）的完整参数说明以 [CREATE EXTERNAL TABLE](https://www.oceanbase.com/docs/common-oceanbase-database-cn-1000000002017037) 为准。
