# 分区交换

#### 说明

当使用一级分区表与非分区表交换数据时，对于 V4.3.5 版本，从 V4.3.5 BP5 版本开始支持一级分区是 List 分区。

#### 说明

对于 OceanBase 数据库 V4.3.5 版本，从 V4.3.5 BP3 版本开始支持 `SUBPARTITION subpartition_name` 子句用于交换二级分区。

#### 说明

对于 OceanBase 数据库 V4.3.5 版本，从 V4.3.5 BP3 版本开始支持二级分区表的一级分区与一级分区表交换数据。
