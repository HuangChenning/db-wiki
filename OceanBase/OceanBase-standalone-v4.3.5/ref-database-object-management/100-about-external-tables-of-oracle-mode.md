# 关于外表与外部文件

#### 说明

文件格式（`FORMAT`）的完整参数以 [CREATE EXTERNAL TABLE](https://www.oceanbase.com/docs/common-oceanbase-database-cn-1000000002017425) 为准。External Catalog 等能力以 MySQL 模式文档为主，Oracle 模式请以实际支持的功能为准。
