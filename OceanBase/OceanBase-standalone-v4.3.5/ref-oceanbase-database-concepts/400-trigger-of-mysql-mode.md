# 触发器

#### 注意

使用 `DELIMITER` 命令修改结束符后，待语句执行结束，请务必将结束符修改为默认符号分号（;）。

#### 说明

- 自 OceanBase 数据库 V4.1.0 BP4 版本起，MySQL 模式下已禁用临时表功能。
- 自 OceanBase 数据库 V4.3.5 BP4 版本起，MySQL 模式下支持临时表功能。
