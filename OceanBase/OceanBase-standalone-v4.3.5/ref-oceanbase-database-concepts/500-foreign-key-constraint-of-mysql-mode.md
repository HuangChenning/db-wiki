# 外键约束

#### 说明

对于 OceanBase 数据库 V4.3.5 版本，从 V4.3.5 BP1 版本开始外键和引用键的类型可以是：

- UNSIGNED FLOAT 和 FLOAT。
- FLOAT 和 UNSIGNED FLOAT
- UNSIGNED DOUBLE 和 DOUBLE。
- DOUBLE 和 UNSIGNED DOUBLE。

#### 注意

OceanBase 数据库 MySQL 模式外键级联操作会激活触发器。
