# 查看租户或表占用的磁盘空间

#### 说明

- MySQL 租户的管理员用户为 `root` 用户，Oracle 租户的管理员用户为 `SYS` 用户。
- 如果需要查看租户回收站对象，则需要使用 `sys` 租户登录数据库。
