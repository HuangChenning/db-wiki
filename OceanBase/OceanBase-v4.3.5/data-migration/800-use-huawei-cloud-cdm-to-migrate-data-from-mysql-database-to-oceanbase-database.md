# 华为云 CDM

#### 注意

连接租户的用户需要拥有该数据库的 `CREATE`、`INSERT`、`DROP` 和 `SELECT` 权限。更多有关用户权限的信息，请参见 [MySQL 模式下的权限分类](../manage/100-permission-classification-of-mysql.md)。

#### 注意

使用 PrivateLink 连接华为云 OceanBase 时，请填写 Endpoint IP 而非域名。
