# OceanBase 分布式版 V4.4.2 文档目录

路径都相对于本文件所在的 `OceanBase-v4.4.2` 目录。检索时先选定一栏，再打开对应的 `contents.md`。

## 快速入门与概述

- `product-updates/contents.md`：What's New。最新功能速递、版本特性解读与产品更新动态。
- `learn-more-about-oceanbase/contents.md`：OceanBase 简介。OceanBase 架构理念、版本差异、核心特性与系统组成。
- `quickstart/contents.md`：快速上手。快速体验部署、SQL 基础入门与示例应用开发。

## 应用开发与生态

- `develop/contents.md`：应用开发。Java、Python、C/C++、Go 等多语言开发实践与规范。
- `ecological-integration/contents.md`：生态集成。Flink、Spark、Canal 等流计算与大数据组件生态集成。
- `ref-database-design-specifications-and-practices/contents.md`：数据库设计规范和约束。库表设计、字符集、索引与 SQL 编写规范和约束。
- `ref-database-proxy/contents.md`：数据库代理。ODP 代理架构、路由策略、连接管理与功能特性。
- `ref-drivers/contents.md`：驱动。各开发语言官方驱动与数据库连接器使用说明。

## 部署与生命周期

- `deploy/contents.md`：OceanBase 部署。单节点、分布式集群、容器化及容灾架构安装部署指南。
- `oceanbase-version-upgrade/contents.md`：OceanBase 升级。跨版本与小版本升级准备、热升级与滚动升级操作指引。
- `data-migration/contents.md`：数据迁移。使用 OMS、DataX 等工具进行数据评估、迁移与实时同步。
- `deploy-practices/contents.md`：集中式版部署实践。使用 OBD 交互式、白屏及配置文件部署实战指南。

## 数据库运维与管理

- `manage/contents.md`：管理数据库。租户管理、资源隔离、集群运维、备份恢复与高可用管控。
- `ref-system-management/contents.md`：系统管理。集群状态监控、节点运维、日常巡检与核心管理操作。
- `ref-database-object-management/contents.md`：数据库对象管理。表、索引、分区、视图、序列等对象的生命周期与维护。

## 分析处理与 AI

- `obap/contents.md`：OceanBase AP。列式存储引擎、向量化执行与实时 AP 复杂分析能力。
- `ob-vector-search/contents.md`：OceanBase AI。向量检索、多模态处理与大模型 AI 应用落地实践。

## 系统原理与调优

- `ref-oceanbase-database-concepts/contents.md`：系统原理。分布式架构、LSM-Tree、Paxos 协议与事务引擎底层原理。
- `ref-performance-tuning-guide/contents.md`：性能调优。执行计划分析、SQL 优化、系统参数调优与高并发调优。

## SQL 与 PL 参考

- `ref-sql-reference/contents.md`：SQL 参考。MySQL 模式与 Oracle 模式完整的 SQL 语法与函数参考。
- `ref-pl-reference/contents.md`：PL 参考。存储过程、自定义函数、系统包与触发器开发参考。
