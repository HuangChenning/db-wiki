# 分区裁剪

#### 注意

在本示例中，所访问的物理分区标识符为 `p0sp0`，该标识符不是二级分区的分区名称。对于模板化二级分区表来说，二级分区的命名规则为 `($part_name)s($subpart_name)`，例如 `p0ssp0`。
