# 身份鉴别

#### 注意

OceanBase 数据库在 Oracle 模式下从 V4.4.2 BP2 版本开始支持密码认证插件机制。

#### 说明

对于 V4.4.2 版本，从 V4.4.2 BP3 版本开始支持认证插件 `ob_sm3_password`。
