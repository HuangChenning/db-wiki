# 用户管理

#### 说明

为了数据库安全，建议您根据自身业务需求来合理授权，请勿随意将该角色赋予用户。

#### 说明

为了保证数据库的安全，不建议您随意向 `PUBLIC` 角色中授予权限。

#### 说明

您也可以直接在用户列表中单击相应用户名，进入用户详情页后，通过基本信息栏中的锁定按钮控制是否锁定用户。

#### 说明

您也可以直接在用户列表中单击用户名，进入用户详情页后，单击用右上角 **修改密码** 按钮，完成对用户密码的修改。

#### 说明

您也可以直接在用户列表中单击用户名，进入用户详情页后，单击右上角 **删除** 按钮， 删除对应用户。

#### 说明

可访问对象删除后，该用户将不能对删除的对象进行访问操作。
