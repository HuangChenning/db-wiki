# 查看 License

#### 说明

OceanBase 集中式版仅支持 SE 类型。

#### 说明

- 单机默认自带一个有效期 180 天的试用 License，当试用 License 即将过期或已过期时，需及时导入正式版 License。在试用期间，**集群管理** 页面上方将置顶 License 试用提示语：OceanBase 集中式版试用 License 即将于 XXXX-XX-XX 过期，请申请正式 License 并正确配置。
- 正式版 License 即将过期或已过期，需导入最新获取的 License。
- 变更 License 中的功能组件后，需重新导入 License。
