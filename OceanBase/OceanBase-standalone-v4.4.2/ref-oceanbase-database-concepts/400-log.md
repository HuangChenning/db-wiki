# 日志

#### 注意

开启 DEBUG 日志将耗费大量资源，在较新版本中，DEBUG 日志在 Release 编译下会自动去掉，即使开启也无法生效。

#### 注意

尽管该配置项的范围是 \[0, +∞)，但 observer 源码中约束了该值不能超过 `MAX_LOG_FILE_COUNT`，即 10240，超过时依然可以设置成功但实际生效值为 MAX_LOG_FILE_COUNT。
