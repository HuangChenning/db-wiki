# 使用 obloader 导入数据

#### 注意

obloader 旁路导入支持连接 **OBServer** 或 **ODP**。版本要求：

- 连接 OBServer：OBServer 为 V4.2.0 及以上。
- 连接 ODP：ODP 为 V4.3.0 及以上，且 OBServer 为 V4.2.1 及以上。

具体以当前使用的导数工具发行说明为准。
