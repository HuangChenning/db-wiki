# 集中式版概述

OceanBase 集中式数据库是一款基于单机分布式一体化架构的数据库产品，从轻量业务到百 TB 级海量数据场景均可覆盖。OceanBase 集中式数据库高度兼容 MySQL 和 Oracle 协议，可无缝迁移现有应用。其提供的原生多租户功能允许多个用户或业务共享同一套数据库实例，实现资源隔离按需使用，灵活管理。集中式版在性能上表现卓越，尤其在读写混合场景中，性能显著优于传统单机数据库。此外集中式版所支持的 HTAP 混合事务与实时分析处理等特性满足业务的多样化需求。

## 产品优势

- **完全自主研发**

  从 0 到 1 完全自主研发，代码级可控，大规模金融核心场景 10 余年可靠性验证。

- **多兼容模式**

  高度兼容 MySQL 和 Oracle 的 SQL 语法及功能特性，同时提供完善的迁移工具， 支持无缝迁移，减少应用改造成本。

- **原生多租户**

  原生多租户允许多个用户或业务共享同一套数据库实例，实现资源隔离按需使用，灵活管理，大幅降低硬件和运维成本。

- **单机分布式一体化**

  一套系统同时支持单机和分布式，兼顾单机部署和分布式部署的性能。

## 核心能力

- **Oracle/MySQL 平滑迁移**

  高度兼容 MySQL 协议及 Oracle 协议，同时提供完善的迁移工具，最小成本搬迁应用与数据。

- **HTAP 混合事务与实时分析处理**

  一份数据既能做事务处理又能实时分析， 通过 HTAP 助力拓展更多可能。

- **高级压缩技术**

  基于 LSM-Tree 的高压缩引擎平衡了“性能”和“压缩”的瓶颈，有效降低存储成本 70% - 90%。

- **单机高性能**

  在 16C 场景下，在 sysbench 所有场景（PointSelect/ReadOnly/WriteOnly/ReadWrite/Insert/Update），性能均优于 MySQL 8.0。

- **海量存储与高吞吐**

  集中式单实例在推荐配置下，可支持百 TB 级海量数据存储，峰值事务处理能力可达百万 TPS，满足从轻量业务到大规模单机负载的扩展需求。

## 应用场景

### 行业头部：核心与非核心统一技术栈

**典型客户：**

金融、政务、能源等行业头部企业

**场景特点：**

- 非核心业务系统（如中后台系统、历史数据、测试环境）
- 多套实例、虚拟化/云原生环境部署

**核心优势：**

- 降低非核心业务成本
- 运维复杂度接近 MySQL/Oracle 集中式版

### 多层级分布式&单机混合架构场景

**典型客户：**

大型连锁酒店、交通控制系统等

**场景特点：**

- 业务系统分为明确的一总部多分部部署
- 总部：分布式版处理高并发业务
- 分部：集中式版处理本地订单，定时与总部同步

**核心优势：**

- 统一适配：总部和分部采用统一技术栈，应用兼容性一致，同构数据同步
- 分部：单机管理简单，运维门槛低

### 国产升级，面向未来的架构之选

- **场景一：MySQL 升级**

  典型客户：需满足自主可控要求的政府单位、国企

  场景特点：无需高可用和高性能，强调兼容性和迁移效率（如政务公积金系统）

  核心优势：高度兼容 MySQL 协议和生态，实现低代码或零代码的应用迁移改造

- **场景二：Oracle 升级**

  典型客户：传统行业（如制造业 ERP 系统）

  核心优势：降低 License 成本，同时保留 PL/SQL 等高兼容性

### 长尾客户轻量级小数据量业务

**典型客户：**

医院、高校、中小制造企业、连锁零售网点等

**场景特点：**

- 轻量级业务（如门诊挂号、校园一卡通、门店进销存）
- 数据量小、并发低、可用性要求低

**核心优势：**

- 成本优势：原生多租户允许多个用户或业务共享同一套数据库实例，弹性利用资源；存储压缩比 70%-90%，硬件成本为 MySQL/Oracle 的 1/3
- 零学习成本：兼容 MySQL 协议和生态，支持 MySQL/Oracle 平滑迁移工具，部署简单

## 集中式版 FAQs

- OceanBase 集中式版和 OceanBase 分布式版本在功能上有什么区别？

  相对于 OceanBase 集中式版，OceanBase 分布式版本的水平扩展能力支持按需扩展每个 zone 里的计算和存储资源，使得数据库的存储、事务处理能力、SQL 计算能力都可以得到水平扩展。同时通过使用 Multi-Paxos 协议，OceanBase 提供金融级高可用能力。在特定容灾场景下，可以提供 RPO=0，RTO\<8s 的无损自动容灾能力。此外 OceanBase 分布式版本还提供了基于“仲裁服务”的高可用能力，可降低多副本高可用的部署硬件成本。在其他方面如 Oracle/MySQL 兼容性、多租户能力、高级压缩特性、AP 能力等功能 OceanBase 集中式版和 OceanBase 分布式版本是保持一致的。

- OceanBase 集中式版提供哪些容灾能力？

  OceanBase 集中式版提供物理备份恢复和租户级物理备库两种容灾方式。租户级主备由于异步同步日志，仅支持最大性能模式，不支持最大保护和最大可用模式。

- OceanBase 集中式版如何扩容？

  首先可以尝试垂直扩容，提升单机规格。在垂直扩容仍无法满足业务要求时，可考虑单机集群转分布式集群，分布式集群支持水平扩缩容，进而实现业务的需求。

- OceanBase 集中式版的生态工具适配怎么样？

  OCP、ODC、OMS 等各类工具都已支持 OceanBase 集中式版。

- OceanBase 集中式版的服务支持如何？

  OceanBase 集中式版为客户提供与分布式版一样的售前、售后、咨询及培训服务。
