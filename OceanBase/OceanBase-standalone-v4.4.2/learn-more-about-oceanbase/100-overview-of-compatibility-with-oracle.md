# 与 Oracle 兼容性概述

#### 说明

在 OceanBase 数据库中，`CREATE MATERIALIZED VIEW LOG` 语法的 `with_clause`（`PRIMARY KEY`、`ROWID`、`SEQUENCE`）的默认行为与 Oracle 数据库是不兼容的。
