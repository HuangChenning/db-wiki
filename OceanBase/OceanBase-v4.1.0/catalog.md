# OceanBase 分布式版 V4.1.0 文档目录

路径都相对于本文件所在的 `OceanBase-v4.1.0` 目录。检索时先选定一栏，再打开对应的 `contents.md`。

## 实践教程与附录

- `release-notes/contents.md`：版本发布记录。各版本 Release Notes、新特性发布与兼容性变更记录。
- `faq/contents.md`：常见问题。安装、开发、运维与迁移过程中的高频疑难问题解答。
- `glossary/contents.md`：OceanBase 术语。OceanBase 核心术语与专业名词速查词典。

## 快速入门与概述

- `learn-more-about-oceanbase/contents.md`：OceanBase 介绍。OceanBase 架构理念、版本差异、核心特性与系统组成。
- `quickstart/contents.md`：快速上手。快速体验部署、SQL 基础入门与示例应用开发。

## 应用开发与生态

- `develop/contents.md`：应用开发。Java、Python、C/C++、Go 等多语言开发实践与规范。

## 部署与生命周期

- `deploy/contents.md`：部署数据库。单节点、分布式集群、容器化及容灾架构安装部署指南。
- `data-migration/contents.md`：数据迁移。使用 OMS、DataX 等工具进行数据评估、迁移与实时同步。

## 数据库运维与管理

- `manage/contents.md`：管理数据库。租户管理、资源隔离、集群运维、备份恢复与高可用管控。

- `ref-oceanbase-database-concepts/contents.md`：系统概念。分布式架构、LSM-Tree、Paxos 协议与事务引擎底层原理。
- `ref-performance-tuning-guide/contents.md`：性能调优。执行计划分析、SQL 优化、系统参数调优与高并发调优。
