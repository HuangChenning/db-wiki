# ob_sql_work_area_percentage

ob_sql_work_area_percentage 用于 SQL 执行的租户内存百分比限制。

| **属性** |   **描述**   |
|--------|------------|
| 参数类型   | int        |
| 默认值    | 5          |
| 取值范围   | \[0, 100\] |
| 生效范围   | GLOBAL     |
