# devname

devname 
============================

devname 用于设置服务进程绑定的网卡设备名。


|      **属性**      | **描述** |
|------------------|--------|
| 参数类型             | 字符串    |
| 默认值              | bond0  |
| 取值范围             | NULL   |
| 是否重启 OBServer 节点生效 | 否      |
