# index_block_cache_priority

'index_block_cache_priority' 用于设置元数据索引微块缓存优先级。

| **属性** | **描述** |
| --- | --- |
| 参数类型 | 整型 |
| 默认值 | 10 |
| 取值范围 | [1, +∞) |
| 是否重启 OBServer 节点生效 | 否 |
