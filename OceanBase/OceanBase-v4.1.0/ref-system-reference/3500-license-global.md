# license

`license` 用于查看 license 的类型。

| **属性** | **描述**  |
|--------|---------|
| 参数类型   | varchar |
| 默认值    | 空字符串    |
| 取值范围   | N/A     |
| 生效范围   | Global  |
| 是否可修改  | 否       |
