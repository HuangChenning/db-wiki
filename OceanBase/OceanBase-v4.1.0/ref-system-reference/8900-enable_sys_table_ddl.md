# enable_sys_table_ddl

enable_sys_table_ddl 
=========================================

`enable_sys_table_ddl` 用于指定是否允许手动创建系统表。


|      **属性**      |                                                 **描述**                                                 |
|------------------|--------------------------------------------------------------------------------------------------------|
| 参数类型             | 布尔类型                |
| 默认值              | False               |
| 取值范围             | <li> False   <li> True    |
| 是否重启 OBServer 节点生效 | 否                   |
