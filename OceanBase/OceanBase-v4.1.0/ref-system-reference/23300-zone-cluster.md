# zone

zone 
=========================

zone 用于设置节点所在的 Zone 的名字。该配置项一般不需要配置。


|      **属性**      | **描述** |
|------------------|--------|
| 参数类型             | 字符串类型  |
| 默认值              | 空值     |
| 取值范围             | NULL   |
| 是否重启 OBServer 节点生效 | 否      |
