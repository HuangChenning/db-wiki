# data_dir

data_dir 
=============================

data_dir 用于设置存储 SSTable 等数据的目录。


| **属性** | **描述** |
|--------|--------|
| 参数类型   | 字符串    |
| 默认值    | store  |
| 取值范围   | NULL   |
| 是否可修改  | 否      |
