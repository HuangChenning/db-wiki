# enable_major_freeze

enable_major_freeze 
========================================

enable_major_freeze 用于设置是否开启自动全局冻结的功能。


|      **属性**      |                                                 **描述**                                                 |
|------------------|--------------------------------------------------------------------------------------------------------|
| 参数类型             | 布尔类型                |
| 默认值              | True                |
| 取值范围             | <li> True   <li> False    |
| 是否重启 OBServer 节点生效 | 否                   |
