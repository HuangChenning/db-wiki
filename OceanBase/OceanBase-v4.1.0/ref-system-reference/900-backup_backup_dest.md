backup_backup_dest

backup_backup_dest 用于设置备份数据备份的目的端。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>从 V4.0.0 版本开始弃用。</p>
</main>

| 参数类型             | 字符串类型 |
| 默认值              | 空字符串  |

| 是否重启 OBServer 节点生效 | 否     |
