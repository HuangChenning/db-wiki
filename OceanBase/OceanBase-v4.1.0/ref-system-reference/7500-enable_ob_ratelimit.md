# enable_ob_ratelimit

enable_ob_ratelimit 
========================================

`enable_ob_ratelimit` 用于在 RPC 连接中，启用区域之间的速率限制。


|      **属性**      |                                                 **描述**                                                 |
|------------------|--------------------------------------------------------------------------------------------------------|
| 参数类型             | 字符串                 |
| 默认值              | False               |
| 取值范围             | <li> False   <li> True    |
| 是否重启 OBServer 节点生效 | 否                   |
