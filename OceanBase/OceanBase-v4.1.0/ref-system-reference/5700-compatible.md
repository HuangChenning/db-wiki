# compatible

`compatible` 用于控制租户下相关功能的兼容行为 ，此配置项不可设置。

| **属性** | **描述** |
| --- | --- |
| 参数类型 | 字符串 |
| 默认值 | 4.1.0.0 |
| 取值范围 | 4.0.0.0 版本开始的若干合法版本   |
| 是否重启 OBServer 节点生效 | 否 |
