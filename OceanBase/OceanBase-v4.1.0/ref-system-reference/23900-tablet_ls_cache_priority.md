# tablet_ls_cache_priority

`tablet_ls_cache_priority` 用于设置 Tablet 映射缓存优先级。

| **属性** | **描述** |
| --- | --- |
| 参数类型 | 整型 |
| 默认值 | 1000 |
| 取值范围 | [1, +∞) |
| 是否重启 OBServer 节点生效 | 否 |
