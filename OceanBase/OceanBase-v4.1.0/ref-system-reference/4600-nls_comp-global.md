# nls_comp

`nls_comp` 表示字符串值的比较规则。

  <main id="notice" type='explain'>
    <h4>说明</h4>
    <p>该变量不支持修改。</p>
  </main>

|  **属性**  |                                                   **描述**                                                   |
|----------|------------------------------------------------------------------------------------------------------------|
| 参数类型     | varchar                 |
| 默认值      | BINARY                  |
| 取值范围     | N/A                     |
| 生效范围     | <li> Global   <li> Session    |
| 是否参与序列化  | 是                       |
| 是否影响计划生成 | 是                       |
