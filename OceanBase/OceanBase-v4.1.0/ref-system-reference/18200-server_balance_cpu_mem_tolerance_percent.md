# server_balance_cpu_mem_tolerance_percent

server_balance_cpu_mem_tolerance_percent 在节点负载均衡策略中，用于设置 CPU 和内存资源不均衡的容忍度。

|      **属性**      |   **描述**   |
|------------------|------------|
| 参数类型             | 整型         |
| 默认值              | 5          |
| 取值范围             | \[1, 100\] |
| 是否重启 OBServer 节点生效 | 否          |
