# ob_compaction_schedule_interval

`ob_compaction_schedule_interval` 用于设置 Compaction 调度的时间间隔。

| 属性 | 描述 |
| --- | --- |
| 参数类型 | 时间类型 |
| 默认值 | 120s |
| 取值范围 | [3s, 5m] |
| 是否重启 OBServer 节点生效 | 否 |
| 是否区分模式 | 否 |
