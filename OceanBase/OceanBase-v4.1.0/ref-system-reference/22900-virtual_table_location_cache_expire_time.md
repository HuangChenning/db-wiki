# virtual_table_location_cache_expire_time

virtual_table_location_cache_expire_time 用于设置虚拟表的位置信息缓存过期时间。

|      **属性**      |  **描述**   |
|------------------|-----------|
| 参数类型             | 时间类型      |
| 默认值              | 8s        |
| 取值范围             | \[1s, +∞) |
| 是否重启 OBServer 节点生效 | 否         |
