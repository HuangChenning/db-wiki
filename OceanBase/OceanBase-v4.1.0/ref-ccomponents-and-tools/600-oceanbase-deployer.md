# OceanBase Deployer（OBD）

OBD 全称为 OceanBase Deployer，是 OceanBase 开源软件的安装部署工具。OBD 同时也是包管理器，可以用来管理 OceanBase 所有的开源软件。

OBD 的主要功能包括：

* 通过 obd demo 命令快速部署 OceanBase 数据库社区版体验环境

* 部署 OceanBase 数据库社区版生产环境

* 为 OceanBase 集群增加白屏监控

* 提供集群管理命令
